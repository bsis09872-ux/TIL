# 새로 배운 개념/ 헷갈리는 개념 정리
- REPL (Read-Eval-Print Loop)
    - 읽기-해석-출력 반복
    - .py 파일과의 차이: repl은 명령창을 나가면 저장되지 않고 다 날아간다.
- 변수: = 이름표 (공간이 아니라 가리키는 참조(reference)/화살표 정도로 보는 것이 더 정확하다)
- 컴퓨터의 기본 기능: 연산 기능 (메모리에 기록)
    - CPU (central processing unit; 중앙 처리 장치)
    - 뇌 역할; 프로그램 명령 처리하고 계산, 논리 연산, 제어 및 입출력 작업 수행
    - 구성: ALU(산술 논리 장치), CU(제어 장치), 레지스터, 캐시 메모리 등
- 동적 타이핑: **Dynamic Typing**
    - **파이썬은 변수 생성 시 자료형을 미리 선언하지 않아요. 프로그램 실행 중에 들어온 값을 보고 자동으로 타입이 결정돼요.**
- **문자 비교연산자 (Character Comparison)**
    - **컴퓨터가 문자를 숫자로 변환해서 비교하기 때문에 가능해요.**
    
    ```
    "apple" < "banana"
    = 'a'(97) < 'b'(98) ✓ → True
    ```
    
    **문자 비교 = 유니코드 숫자 비교!**
    
- **유니코드 (Unicode)**
    - **모든 문자를 고유한 숫자 코드로 변환하는 국제 표준 규칙**
    - **국문(한글)도 가능해요! 🇰🇷/ 한글도 유니코드 값을 가지고 있어서 비교 가능해요.**
        - **다만: 한글은 음절 단위 코드라 음절 기반 비교만 가능해요!**

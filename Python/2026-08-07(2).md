## LECTURE NOTE

### 1. 조건문 `if / elif / else`

조건문은 **조건의 True / False 결과에 따라 실행할 코드를 결정하는 구문**이다. 조건식에는 비교 연산자와 논리 연산자 등을 사용할 수 있다.

```python
if 조건1:
    # 조건1이 True일 때

elif 조건2:
    # 조건1은 False이고 조건2가 True일 때

else:
    # 앞의 모든 조건이 False일 때
```

`if`, `elif`, `else`는 같은 위치에 작성하고, 각 조건에서 실행할 코드만 안쪽으로 들여쓴다.

#### 조건 순서

앞의 조건이 `True`가 되면 이후 `elif`는 확인하지 않기 때문에 **조건의 순서가 중요하다.**

```python
score = 95

# 잘못된 예
if score >= 80:
    print("B학점")
elif score >= 90:
    print("A학점")
```

95점도 `score >= 80`을 만족하므로 첫 번째 조건에서 실행이 끝난다.

```python
# 수정
if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
```

조건문 안에 다시 조건문을 작성하는 **중첩 조건문**도 사용할 수 있지만, 구조가 복잡해지면 가독성이 떨어질 수 있다. 단순한 조건은 `and`, `or` 등의 논리 연산자를 활용할 수 있다.

### 2. 반복문

반복문은 동일하거나 유사한 작업을 여러 번 수행할 때 사용한다.

#### `break`와 `continue`

```text
break
→ 현재 반복문 전체 종료

continue
→ 현재 회차만 건너뛰고 다음 반복 진행
```

```python
for num in range(10):
    if num == 5:
        break
```

```python
for num in range(10):
    if num == 5:
        continue
```

`break`는 무한 루프를 강제로 종료할 때도 사용할 수 있다.

---

### 3. `for`문과 `range()`

`for`문은 반복 횟수가 정해져 있거나 컬렉션의 요소를 하나씩 순회할 때 사용한다.

```python
for i in range(5):
    print(i)
```

반복 변수는 관례적으로 `i`, 중첩 반복에서는 `j`, `k` 등을 사용한다. 값 자체가 필요하지 않은 위치에는 `_`를 사용할 수도 있다.

```python
for _, value in user.items():
    print(value)
```

Dictionary의 `items()`는 언패킹과 함께 사용할 수 있다.

```python
for key, value in user.items():
    print(key, value)
```

#### `range()`

```python
range(반복횟수)
range(시작, 종료)
range(시작, 종료, 증감단위)
```

```python
range(5)         # 0, 1, 2, 3, 4
range(2, 5)      # 2, 3, 4
range(2, 10, 2)  # 2, 4, 6, 8
```

**종료값은 포함되지 않는다.**

### 4. 이중 반복문

반복문 안에 또 다른 반복문을 사용할 수 있다.

```python
for i in range(2, 10):
    print("-" * 5, i, "단", "-" * 5)

    for j in range(1, 10):
        print(f"{i} x {j} = {i * j}")
```

이처럼 컬렉션의 요소를 하나씩 확인하는 과정을 **Iteration / Traversal(순회)** 이라고 한다.

---

### 5. 리스트 컴프리헨션

반복을 통해 새로운 리스트를 만드는 코드를 간결하게 작성할 수 있다.

기존 방식:

```python
result = []
nums = [1, 2, 3, 4, 5]

for num in nums:
    result.append(num ** 2)
```

리스트 컴프리헨션:

```python
nums = [1, 2, 3, 4, 5]

result = [num ** 2 for num in nums]
```

이중 반복문도 표현할 수 있다.

```python
result = [
    f"{i} x {j} = {i * j}"
    for i in range(2, 10)
    for j in range(1, 10)
]
```

### 6. `while`문

`while`문은 조건이 `True`인 동안 반복한다.

```python
while 조건:
    # 반복 실행
```

- 반복 횟수가 비교적 명확할 때 → `for`
- 특정 조건이 유지되는 동안 반복할 때 → `while`

---

### 7. Iterable / Iterator / Iteration

| 용어 | 의미 | 예시 |
|---|---|---|
| Iterable | 반복 가능한 객체 | `list`, `str`, `dict` |
| Iterator | 값을 하나씩 꺼내는 객체 | `iter(list)` |
| Iteration | 반복해서 값을 처리하는 과정 | `for` 순회 |

### 8. 함수(Function)

함수는 특정 작업을 하나의 기능으로 묶어 재사용하기 위한 코드이다.

```text
입력 → 처리 → 출력
```

기본 구조:

```python
def 함수이름(매개변수):
    # 처리
    return 반환값
```

호출:

```python
함수이름(인수)
```

예:

```python
def add(a, b):
    result = a + b
    return result

add(10, 20)
```

### 1차 시도

```python
for item in order_database:
    ...
```

List 안의 Dictionary를 `item`으로 하나씩 꺼내는 데는 성공했다.

하지만 Dictionary에서 원하는 데이터를 꺼내기 위해 다음과 같이 언패킹을 시도하면서 문제가 발생했다.

```python
completed, price = item
```

### 2차 시도

필요한 요소를 변수에 할당하는 방법을 시도했다.

```python
_, highest_number, highest_order = item
```

코드는 오류 없이 실행되었지만 원하는 출력 결과가 나오지 않았다.

### 3차 수정

이미 반복문에서 현재 Dictionary를 `item`으로 꺼냈는데, 조건문에서 다시 `order_database`를 대상으로 Key를 조회하고 있었다.

현재 처리 중인 데이터인 `item`에서 Key를 조회하도록 변경했다.

```python
item["키"]
```

구조를 다음처럼 이해했다.

```text
order_database
      ↓
for문으로 주문 1개 꺼내기
      ↓
item (Dictionary)
      ↓
item["key"]로 값 조회
      ↓
if 조건 판별
```

### 4차 수정

`print()`가 `if`문 내부에 잘못 배치되어 최종 결과가 원하는 위치에서 출력되지 않았다.

반복과 조건 처리가 완료된 이후 출력되도록 **들여쓰기 위치를 수정**했다.

### 실습에서 이해한 내용

이번 문제에서는 문법 자체보다 **현재 반복문이 어떤 데이터를 다루고 있는지를 추적하는 것**이 중요했다.

```text
List
 ↓
for문
 ↓
Dictionary 하나 = item
 ↓
item["key"]로 필요한 값 조회
 ↓
if 조건 판별
 ↓
값 누적
 ↓
반복 종료
 ↓
최종 결과 출력
```

특히 다음 내용을 다시 확인했다.

- 중첩 자료구조에서는 **현재 반복 중인 객체가 무엇인지** 먼저 확인한다.
- Dictionary의 값을 사용할 때는 현재 Dictionary의 Key를 기준으로 조회한다.
- Python에서는 **들여쓰기 위치가 실행 범위와 횟수에 직접 영향을 준다.**
- `print()`를 반복문 내부에 두면 반복마다 출력되고, 반복문 밖에 두면 누적 계산이 끝난 뒤 최종 결과를 출력할 수 있다.

## LECTURE NOTE
### 이터레이터와 제너레이터
1. 이터러블(Iterable): 반복 가능한 객체
2. 이터레이터(Iterator): 반복자
- 반복을 하려면 이터레이터 객체 생성 (__iter__)
    > 호출: iter(...)
- 순서를 한칸씩 이동하면서 요소 조회(__next__)
    > 호출: next(...)
- `StopIteration:` 다 돌고 나면 멈춘다.

3. 제너레이터(Generator)
- next() : 호출/**재개**
- yield : **분기** 
- 비동기 처리 방식

비고|동기|비동기
|----|-------|------|
작업 | 순서대로 실행| 순서대로 작업 시작
결과 | 순서대로 도출| 먼저 처리된 순서대로 도출

- 비동기 의미(예시) - 식당 메뉴 주문 후 나오는 순서.

### Daily Quests
1. 이터러블 객체는 __iter__ 메서드를 통해 이터레이터를 생성하고, 생성된 이터레이터는 __next__ 메서드로 다음 요소를 하나씩 반환합니다. 이터러블 자체는 __next__를 갖지 않으며, 순회가 끝나면 None이 아닌 StopIteration 예외가 발생합니다.
2. from 키워드는 모듈 전체가 아닌 필요한 특정 함수나 클래스만 선택적으로 가져오는 방식이므로, 모듈 전체를 불러오는 import보다 메모리를 더 많이 쓴다는 설명은 교안 내용과 맞지 않는 틀린 설명입니다. 나머지 선지는 각 키워드의 특징을 올바르게 설명하고 있습니다.
3. yield는 값을 반환한 후 함수의 실행 상태(지역 변수, 실행 위치 등)를 메모리에 보존한 채 함수를 일시 정지시킵니다. 이는 실행 상태를 완전히 소멸시키는 return과 구분되는 핵심 특징입니다.
4. 리스트 컴프리헨션은 대괄호 구조로 모든 결과값을 즉시 계산하여 메모리에 적재하므로 데이터 개수에 비례해 메모리가 증가하지만, 제너레이터 표현식은 소괄호 구조로 규칙만 저장해 두었다가 필요할 때 값을 생성하므로 항상 수백 바이트 수준의 고정된 메모리만 사용합니다.
5. 파이썬 패키지 구조에서 현재 모듈 기준으로 '나를 감싸고 있는 상위 폴더 위치'를 표시할 때 사용하는 상대 경로 기호는 무엇인가요? 단일 점(.)은 현재 폴더 위치를, 더블 점(..)은 상위 폴더 위치를 나타내는 상대 경로 표기법입니다. 이러한 상대 경로는 패키지 전체가 하나의 구조로 실행될 때만 정상 동작합니다.

### 실습
```
import random

for _ in range(7):
    rand_num = random.randint(1,6)
    print(rand_num)
```
- for문에서 range(7)은 7번 반복할 숫자를 의미. 내부 random.randint(1,6)은 1부터 6까지 안에서 난수 생성을 의미.
- range(1,4)는 콤마로 범위 표시, 마지막 숫자를 포함하지 않는다. (1부터 3까지)
- randint(1,4)는 콤마로 범위 표시, 마지막 숫자 포함한다. (1부터 4까지)

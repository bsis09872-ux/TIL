## REVIEW

### `range()`

`range()`는 일정한 범위의 숫자를 생성하는 Python 내장 함수이다. 반복문에서 반복 횟수나 숫자의 범위를 지정할 때 사용할 수 있다.

```python
range(반복횟수)
range(시작, 종료)
range(시작, 종료, 증감단위)
```

예:

```python
for i in range(1, 6):
    print(i)
```

`1`부터 `5`까지 반복하며, **종료값은 포함되지 않는다.**

### 2. Heap과 함수 객체

Python에서는 숫자나 문자열뿐만 아니라 **함수도 객체(Object)** 로 다뤄진다.

```python
def calc(x):
    return x + 10
```

`calc`라는 이름은 함수 자체가 아니라 생성된 **함수 객체를 참조하는 이름**으로 이해할 수 있다.

```text
calc
  │
  └──→ Function Object
             │
             └──→ Code Object
```

수업에서는 함수 객체 내부에 함수 실행에 필요한 코드 정보를 가진 **Code Object**가 연결되어 있다고 학습했다.

하나의 객체를 여러 이름이 참조하는 것도 가능하다.

```python
def calc(x):
    return x + 10

a = calc

print(a is calc)
```

```text
True
```

### 3. `is`: 같은 객체를 참조하는지 확인

`is`는 두 대상이 **동일한 객체를 참조하고 있는지** 확인한다.

```python
a = [1, 2, 3]
b = a

print(a is b)
```

```text
True
```

반면 `==`는 두 객체의 **값이 같은지** 비교한다.

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)   # True
print(a is b)   # False
```

즉,

```text
==  → 값이 같은가?
is  → 같은 객체인가?
```

### 4. Stack과 Call Stack

**Stack**은 가장 나중에 들어온 데이터가 가장 먼저 나오는 **LIFO(Last In, First Out)** 구조이다.

```text
┌─────────┐
│ add()   │ ← 나중에 들어옴 / 먼저 나감
├─────────┤
│ func()  │ ← 먼저 들어옴 / 나중에 나감
└─────────┘
```

Python은 함수 호출을 관리할 때 이러한 Stack 구조를 사용한다. 이를 **Call Stack**이라고 한다.

예를 들어 `func()`가 실행되는 도중 `add()`를 호출한다면,

```python
def add(num1, num2):
    return num1 + num2

def func(num):
    result = add(10, 20)
    return num + result

func(40)
```

함수 호출 순서는 다음과 같다.

```text
func(40)
   ↓
add(10, 20)
```

하지만 함수가 종료되는 순서는 반대이다.

```text
add()
   ↓
func()
```

즉, **가장 나중에 호출된 함수부터 실행을 마치고 이전 함수로 돌아간다.**

### 5. 함수 호출과 Frame

함수를 호출하면 해당 함수의 실행 정보를 관리하기 위한 **Frame**이 만들어진다.

수업에서는 Python 내부의 `PyFrameObject`와 그 안에서 지역 변수를 관리하는 `f_locals`를 확인했다.

```text
func(40) 호출

┌─────────────────────┐
│ Frame: func         │
│                     │
│ f_locals            │
│ num = 40            │
│ result = ...        │
└─────────────────────┘
```

`func()` 안에서 `add(10, 20)`을 호출하면 새로운 Frame이 Call Stack에 추가된다.

```text
┌─────────────────────┐
│ Frame: add          │ ← 현재 실행
│ num1 = 10           │
│ num2 = 20           │
├─────────────────────┤
│ Frame: func         │
│ num = 40            │
│ result = ...        │
└─────────────────────┘
```

`add()`의 실행이 끝나면 해당 Frame이 먼저 제거되고 다시 `func()`의 실행으로 돌아간다.

따라서 **함수 객체 자체**와 **함수를 호출할 때 만들어지는 Frame**은 구분해서 이해해야 한다.

```text
함수 정의
→ 함수 객체

함수 호출
→ Frame 생성
→ 지역 변수 사용
→ 함수 실행
→ 함수 종료
→ Frame 제거
```

### 6. Parameter와 Argument

함수에 값을 전달할 때 **매개변수(Parameter)** 와 **인수(Argument)** 를 구분한다.

```python
def calc(x):
    return x + 10

calc(10)
```

- `x` → **Parameter**: 함수를 정의할 때 값을 받기 위해 선언하는 변수
- `10` → **Argument**: 함수를 호출할 때 실제로 전달하는 값

```text
함수 정의 → Parameter
함수 호출 → Argument
```

### 7. 함수에 인수를 전달하는 방법

**위치 인수(Positional Argument)** 는 매개변수의 순서에 따라 값을 전달한다.

```python
def add(num1, num2):
    return num1 + num2

add(10, 20)
```

**키워드 인수(Keyword Argument)** 는 매개변수의 이름을 직접 지정한다.

```python
add(num2=20, num1=10)
```

키워드 인수는 이름을 직접 지정하므로 순서를 바꿀 수 있다. 위치 인수와 함께 사용할 때는 **위치 인수를 먼저 작성하고 키워드 인수를 뒤에 작성한다.**

---

### 8. 기본값 매개변수

매개변수에는 기본값을 설정할 수 있다.

```python
def greet(name, message="Hello"):
    return f"{message}, {name}"
```

`message`를 전달하지 않으면 미리 지정한 `"Hello"`가 사용된다.

```python
greet("Alice")
```

기본값이 없는 매개변수를 먼저 작성하고, **기본값이 있는 매개변수는 뒤쪽에 정의한다.**

---

### 9. 가변 인수 `*args`와 `**kwargs`

전달할 인수의 개수가 일정하지 않을 때 가변 인수를 사용할 수 있다.

```python
def add(*args):
    return sum(args)

add(10, 20, 30)
```

수업에서 배운 구분은 다음과 같다.

```text
*args
→ 개수가 정해지지 않은 위치 인수

**kwargs
→ 개수가 정해지지 않은 키워드 인수
```

### 10. `return`

`return`은 결과를 호출한 곳으로 반환하며, **`return`을 만나면 현재 함수의 실행이 즉시 종료된다.**

```python
def add(a, b):
    return a + b

result = add(10, 20)
```

```text
add(10, 20)
     ↓
함수 실행
     ↓
return 30
     ↓
함수 종료
     ↓
호출한 위치로 30 반환
```

여러 값을 반환하는 것처럼 작성할 수도 있다.

```python
def calc():
    return 10, 20, 30
```

이 경우 여러 개의 독립적인 반환값이 생기는 것이 아니라, 이전에 배운 **패킹**에 의해 하나의 튜플로 반환된다.

```python
result = calc()

print(result)
# (10, 20, 30)
```

필요하면 언패킹하여 사용할 수 있다.

```python
a, b, c = calc()
```

### 11. 오늘 배운 함수의 실행 흐름

이번 수업의 메모리와 함수 개념을 연결하면 다음과 같다.

```text
함수 정의
   ↓
함수 객체 생성
   ↓
함수 이름이 객체를 참조
   ↓
함수 호출
   ↓
Call Stack에 Frame 생성
   ↓
매개변수 · 지역 변수 사용
   ↓
함수 코드 실행
   ↓
return
   ↓
함수 실행 종료
   ↓
Frame 제거
```

즉, **Heap의 함수 객체**와 **Call Stack에서 실제 함수를 실행하기 위해 만들어지는 Frame**을 구분해서 이해하는 것이 핵심이다.

## 오늘 배운 내용은 어디에 사용할까?

### `range()` + `for`

정해진 횟수만큼 작업하거나 여러 데이터를 순차적으로 처리할 때 사용할 수 있다.

예: 주문 목록 처리, 데이터 행 반복, 여러 사용자 정보 확인

### `if`

조건에 따라 서로 다른 처리를 해야 할 때 사용한다.

예: 점수에 따른 등급 분류, 재고 부족 여부 확인, 특정 기준 이상의 데이터 추출

### 함수

반복해서 사용하는 작업을 하나의 기능으로 만들어 재사용할 때 활용할 수 있다.

이번 실습처럼 **데이터를 입력받아 → 반복하고 → 조건을 확인하고 → 결과를 계산하는 과정**을 하나의 함수로 만들 수 있다.

```text
데이터 입력
   ↓
for 반복
   ↓
if 조건 판단
   ↓
계산
   ↓
return / 결과 출력
```

## 오늘 이해한 내용

- `range()`는 반복할 숫자의 범위를 생성하며 종료값은 포함하지 않는다.
- Python에서는 변수들이 같은 객체를 참조할 수 있으며 `is`로 동일한 객체인지 확인할 수 있다.
- `return`을 만나면 함수가 즉시 종료되고 결과가 호출한 곳으로 반환된다.
- Python에서는 들여쓰기가 코드의 실행 범위를 결정하기 때문에 중요하다.
- `for`, `if`, 함수를 함께 사용하면 여러 데이터를 반복해서 검사하고 원하는 결과를 계산할 수 있다.
- 코드가 오류 없이 실행되는 것과 **원하는 횟수와 위치에서 실행되는 것**은 별개의 문제이므로 실행 흐름도 확인해야 한다.

# Python 자료구조와 연산

> 📅 2026.08.10

오늘은 Python의 시퀀스 자료구조인 문자열, 리스트, 튜플과 딕셔너리, 집합(set)을 학습했다. 또한 자료형 변환, 패킹과 언패킹, 얕은 복사와 깊은 복사의 차이를 정리했다.

## 헷갈리는 개념 정리

### 복합 대입 연산자

| 연산자 | 의미 | 예시 |
|---|---|---|
| `+=` | 더하기 후 대입 | `score += 50` |
| `-=` | 빼기 후 대입 | `count -= 1` |
| `*=` | 곱하기 후 대입 | `price *= 1.1` |
| `/=` | 나누기 후 대입 | `value /= 2` |
| `//=` | 몫 연산 후 대입 | `num //= 5` |
| `%=` | 나머지 연산 후 대입 | `remainder %= 10` |

실무에서는 점수 누적, 재고 관리, 가격 조정처럼 기존 값을 갱신할 때 자주 사용한다.

## 오늘 배운 내용

### 1. 시퀀스 자료구조

시퀀스 자료구조는 **순서가 있는 데이터의 묶음**이다.

대표적으로 문자열, 리스트, 튜플이 있으며 인덱싱과 슬라이싱을 사용할 수 있다.

### 문자열

문자열은 여러 문자가 순서대로 나열된 시퀀스이다.

```python
text = "Python"

text[0]      # 'P'
text[1:4]    # 'yth'
```

`[]` 인덱스 연산자로 특정 위치에 접근할 수 있고 슬라이싱도 가능하다.

---

### 2. 리스트(List)

리스트는 `[]`로 표현하며 **수정 가능한(Mutable)** 시퀀스 자료구조이다.

#### 추가(Create)

```python
fruits.append("사과")
fruits.insert(1, "오렌지")
fruits.extend(["포도", "수박"])
```

- `append(요소)` : 리스트 끝에 요소 하나 추가
- `insert(위치, 요소)` : 원하는 위치에 요소 추가
- `extend(컬렉션)` : 리스트 끝에 여러 요소 추가

리스트끼리 `+` 연산을 사용할 수도 있다.

```python
new_list = [1, 2] + [3, 4]
```

이 경우 기존 리스트를 수정하는 것이 아니라 **새로운 리스트 객체가 생성된다.**

#### 조회(Read)

```python
fruits[1]
fruits.index("사과")
```

- `fruits[1]` : 인덱스로 요소 조회
- `index(요소)` : 특정 요소의 위치 확인

#### 수정(Update)

```python
fruits[1] = "오렌지"
```

인덱스로 접근해 새로운 값을 대입한다.

#### 삭제(Delete)

```python
fruits.remove("사과")
fruits.clear()
```

- `remove(요소)` : 처음 발견한 해당 요소 삭제
- `clear()` : 전체 요소 삭제

#### 기타 메서드

```python
fruits.sort()
fruits.sort(reverse=True)
fruits.reverse()
fruits.count("사과")
```

- `sort()` : 오름차순 정렬
- `sort(reverse=True)` : 내림차순 정렬
- `reverse()` : 현재 순서를 반대로 뒤집기
- `count(요소)` : 특정 요소의 등장 횟수 확인

---

### 3. 튜플(Tuple)

튜플은 `()`로 표현하며 **수정할 수 없는(Immutable)** 시퀀스 자료구조이다.

```python
data = (10, 20, 30)
```

리스트처럼 인덱싱과 슬라이싱은 가능하지만 요소를 수정할 수는 없다.

```python
data[0]
data[1:3]
```

주요 메서드는 다음과 같다.

```python
data.count(10)
data.index(20)
```

값이 하나인 튜플을 만들 때는 반드시 쉼표가 필요하다.

```python
data = (10,)
```

소괄호를 생략하고 쉼표로만 정의할 수도 있다.

```python
data = 10, 20, 30
```

---

### 4. 인덱싱과 슬라이싱

음수 인덱스를 사용하면 오른쪽부터 접근한다.

```python
data[-1]
```

슬라이싱은 특정 범위의 값을 가져올 때 사용한다.

```python
data[2:]       # 2번부터 끝까지
data[:3]       # 처음부터 3번 직전까지
data[2:5]      # 2 이상, 5 미만
data[::2]      # 두 칸씩 이동
```

종료 인덱스는 포함되지 않는다.

슬라이싱 결과는 원본과 같은 종류의 시퀀스로 생성된다.

- 리스트 슬라이싱 → 리스트
- 튜플 슬라이싱 → 튜플
- 문자열 슬라이싱 → 문자열

### 시퀀스 연산

```python
a + b
a * 3
x in a
```

- `+` : 시퀀스를 연결해 새로운 객체 생성
- `* 숫자` : 해당 횟수만큼 반복한 새로운 시퀀스 생성
- `요소 in 시퀀스` : 포함 여부를 `True` 또는 `False`로 반환

## 5. 자료형 변환

다른 컬렉션을 원하는 자료구조로 변환할 수 있다.

| 함수 | 용도 | 예시 |
|---|---|---|
| `list()` | 리스트로 변환 | `list("ABC") → ['A', 'B', 'C']` |
| `tuple()` | 튜플로 변환 | `tuple([1, 2, 3]) → (1, 2, 3)` |
| `set()` | 집합으로 변환 | `set([1, 2, 2, 3]) → {1, 2, 3}` |
| `dict()` | 딕셔너리로 변환 | 키-값 쌍 형태 필요 |

자료형을 변환하면 변환된 자료구조의 특성을 따르게 된다.

예를 들어 튜플은 수정할 수 없고, 집합은 중복을 허용하지 않으며 순서가 없다.

## 6. 패킹과 언패킹

### 패킹(Packing)

여러 값을 하나의 자료구조로 묶는 것이다.

```python
data = 10, 20, 30
```

자동으로 튜플이 생성된다.

### 언패킹(Unpacking)

묶여 있는 값을 여러 변수에 나누어 대입한다.

```python
x, y, z = data
```

```text
x = 10
y = 20
z = 30
```

변수 값을 서로 교환할 때도 간결하게 사용할 수 있다.

```python
a, b = b, a
```

기존 방식처럼 임시 변수를 따로 만들 필요가 없다.

---

## 7. 딕셔너리(Dictionary)

딕셔너리는 **Key-Value 쌍**으로 데이터를 저장하는 자료구조이다.

```python
person = {
    "name": "Alice",
    "age": 25
}
```

- `key` : 값을 찾기 위한 식별자
- `value` : key와 연결된 실제 값
- key는 중복될 수 없음
- value는 중복 가능
- 리스트처럼 변경 가능한 자료형은 key로 사용할 수 없음

### 추가(Create)

없는 key에 값을 대입하면 새로운 항목이 추가된다.

```python
person["city"] = "Seoul"
```

### 조회(Read)

```python
person["name"]
```

존재하지 않는 key를 조회하면 `KeyError`가 발생한다.

`get()`을 사용하면 오류 대신 `None` 또는 지정한 기본값을 받을 수 있다.

```python
person.get("name")
person.get("job", "없음")
```

### 주요 메서드

```python
person.keys()
person.values()
person.items()
```

- `keys()` : 모든 key를 담은 view
- `values()` : 모든 value를 담은 view
- `items()` : `(key, value)` 쌍을 담은 view

### 수정(Update)

이미 존재하는 key에 값을 다시 대입하면 수정된다.

```python
person["age"] = 26
```

여러 값을 한 번에 수정하거나 추가할 수도 있다.

```python
person.update({
    "age": 26,
    "city": "Busan"
})
```

### 삭제(Delete)

```python
del person["age"]
person.clear()
```

## 8. 집합(Set)

집합은 **중복을 허용하지 않고 순서가 정해져 있지 않은 자료구조**이다.

```python
numbers = {1, 2, 3}
```

딕셔너리도 `{}`를 사용하지만 딕셔너리는 `key: value` 형태이고, 집합은 값만 저장한다.

집합은 순서가 없기 때문에 인덱싱과 슬라이싱이 불가능하다.

### 집합 연산

```python
a | b
a & b
a - b
a ^ b
```

| 연산 | 의미 | 메서드 |
|---|---|---|
| `a \| b` | 합집합 | `a.union(b)` |
| `a & b` | 교집합 | `a.intersection(b)` |
| `a - b` | 차집합 | `a.difference(b)` |
| `a ^ b` | 대칭차집합 | `a.symmetric_difference(b)` |

리스트나 튜플을 집합으로 변환할 수 있다.

```python
set([1, 2, 2, 3])
```

결과:

```python
{1, 2, 3}
```

중복이 제거되지만 순서는 보장되지 않는다.

## 9. 얕은 복사와 깊은 복사

중첩된 자료구조를 복사할 때는 복사의 깊이에 주의해야 한다.

### 얕은 복사(Shallow Copy)

```python
new_data = data.copy()
```

바깥쪽 객체는 새로 생성되지만 내부에 중첩된 객체는 원본과 같은 객체를 참조할 수 있다.

따라서 내부 리스트를 수정하면 원본에도 영향을 줄 수 있다.

### 깊은 복사(Deep Copy)

```python
import copy

new_data = copy.deepcopy(data)
```

바깥쪽과 내부 객체까지 독립적으로 복사한다.

| 상황 | 사용 |
|---|---|
| 단순 리스트/딕셔너리 복사 | `copy()` |
| 중첩 자료구조를 완전히 독립적으로 복사 | `copy.deepcopy()` |
| 원본 보존이 반드시 필요한 경우 | 깊은 복사 고려 |

---

## 새롭게 이해한 내용

- 리스트와 튜플은 둘 다 시퀀스지만 **리스트는 가변, 튜플은 불변**이다.
- `+` 연산으로 리스트나 튜플을 합치면 기존 객체를 수정하는 것이 아니라 새로운 객체가 만들어진다.
- 집합은 중복 제거에 유용하지만 순서가 없기 때문에 인덱싱과 슬라이싱을 사용할 수 없다.
- `get()`을 사용하면 딕셔너리에 key가 없어도 `KeyError` 없이 안전하게 조회할 수 있다.
- 패킹과 언패킹을 사용하면 여러 값을 간결하게 처리할 수 있다.
- 중첩 자료구조를 복사할 때는 얕은 복사와 깊은 복사의 차이를 고려해야 한다.

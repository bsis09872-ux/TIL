# 헷갈리는 개념 정리
연산자	의미	예시
+=	더하기 후 대입	score += 50
-=	빼기 후 대입	count -= 1
*=	곱하기 후 대입	price *= 1.1
/=	나누기 후 대입	value /= 2
//=	몫 후 대입	num //= 5
%=	나머지 후 대입	remainder %= 10

> 실무 활용 예시: 점수 누적, 재고 관리, 가격 조정

# 배운 내용 중 새롭게 알게 된 내용

함수	용도	예시
list()	리스트로 변환	list("ABC") → ['A', 'B', 'C']
tuple()	튜플로 변환	tuple([1, 2, 3]) → (1, 2, 3)
set()	집합으로 변환	set([1, 2, 2, 3]) → {1, 2, 3}
dict()	딕셔너리로 변환	특정 형식 필요

> 한 가지 주의할 점: 변환 후 자료구조의 특성이 바뀐다는 거예요. 예를 들어 튜플은 수정 불가능하고, 집합은 순서가 없어요.

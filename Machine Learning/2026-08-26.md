## LECTURE NOTE

### 1. 선형회귀 (Linear Regression)

선형회귀에서는 데이터의 관계를 하나의 선으로 표현하여 값을 예측한다.

- **선**: 공식, 알고리즘, 예측값을 만드는 모델
- **점들**: 실제 데이터

```text
y = ax + b
```

이러한 식을 이용해 입력값으로부터 결과를 예측한다.

| 기호 | 의미 |
|---|---|
| `x` | Feature(특성), 입력값 |
| `y` | Label, 실제값/정답 |
| `ŷ` | 모델이 예측한 값 |
| `a`, `w` | Weight(가중치), 기울기 |
| `b` | Bias(편향), 절편 |

모델은 결국 **적절한 `w`와 `b`를 찾아 실제값에 가까운 예측값을 만드는 것**을 목표로 한다.

---

### 2. Loss Function ⭐

예측을 잘하면 실제값과 예측값의 차이인 **오차(Error)** 가 작아진다.

```text
Error = y - ŷ
```

- `y`: 실제값
- `ŷ`: 예측값

하지만 각각의 오차에는 음수와 양수가 함께 존재할 수 있기 때문에 단순히 모두 더하는 것만으로는 모델 전체의 오차를 평가하기 어렵다.

따라서 여러 오차를 하나의 대표값으로 계산하는 **Loss Function(손실 함수)** 을 사용한다.

#### MSE (Mean Squared Error)

**평균 제곱 오차**

1. 오차를 제곱하여 계산
2. 매끄러운 곡선 형태로 미분 가능 → 최적의 가중치를 찾는 데 활용 가능
3. 큰 오차를 제곱하기 때문에 이상치에 민감

```text
0.2 → 0.04
10  → 100
```

> MSE는 회귀 문제에서 많이 사용하는 대표적인 손실 함수이다.

#### MAE (Mean Absolute Error)

**평균 절대 오차**

1. 오차의 절댓값을 사용
2. 오차의 크기를 직관적으로 확인 가능
3. MSE에 비해 미분이 매끄럽지 않은 지점이 존재

> **[참고]** 제곱 오차는 U자 형태, 절대 오차는 V자 형태로 생각할 수 있다.

---

### 3. 모델 학습과 최적화

모델의 목적은 **Loss 값을 최대한 줄여 예측을 실제값에 가깝게 만드는 것**이다.

처음에는 `w`, `b`에 초기값을 설정하고 학습을 시작한다.

```text
w, b 초기값 설정
    ↓
예측
    ↓
Loss 확인
    ↓
Loss가 크면 w, b 조정
    ↓
다시 예측
    ↓
다시 Loss 확인
    ↓
반복
```

즉, 학습의 목적은 **Loss가 낮아지는 방향의 최적의 가중치와 절편을 결정하는 것**이다.

---

### 4. 경사하강법 (Gradient Descent) ⭐

현재 가중치에서 Loss를 줄이려면 **어느 방향으로 가중치를 움직여야 하는지** 알아야 한다.

이를 위해 Loss를 가중치에 대해 미분하여 **Gradient(기울기)** 를 구한다.

```text
∂Loss / ∂W
```

Gradient를 이용하여 Loss가 감소하는 방향으로 가중치를 조금씩 이동시키는 방법이 **Gradient Descent(경사하강법)** 이다.

가중치 업데이트의 기본 형태:

```text
W_new = W_old - α × (∂Loss / ∂W)
```

즉,

```text
현재 가중치
   ↓
Gradient 계산
   ↓
Loss가 감소하는 방향 확인
   ↓
가중치 업데이트
   ↓
반복
```

Loss의 최솟값에 가까워질수록 기울기도 점차 `0`에 가까워진다.

---

### 5. Learning Rate (학습률)

위 공식에서 `α(alpha)`는 **Learning Rate(학습률)** 이다.

```text
α = Learning Rate
```

- 가중치를 한 번에 얼마나 조정할지 결정
- 점진적으로 가중치를 조정하기 위한 값
- 예: `0.001`, `0.0001`
- 모델 개발자가 직접 설정하는 **Hyperparameter**

학습률이 너무 크면 최솟값을 지나칠 수 있고, 너무 작으면 학습 속도가 느려질 수 있다.

#### Model Parameter vs Hyperparameter

- `w`, `b` → **Model Parameter**
  - 모델이 학습 과정에서 결정하는 값

- Learning Rate → **Hyperparameter**
  - 모델 학습 전에 개발자가 설정하는 값

---

### 6. Optimizer ⭐

> **가중치를 업데이트하는 방법**

Optimizer는 Gradient를 이용하여 **어떤 방식으로 가중치를 업데이트할지 결정**한다.

즉,

```text
Loss 계산
    ↓
Gradient 계산
    ↓
Optimizer
    ↓
Weight 업데이트
```

#### Optimizer 종류

- **SGD (Stochastic Gradient Descent)**
  - 확률적 경사하강법

- **Momentum (관성)**
  - 이전 업데이트 방향을 고려하여 관성을 주는 방식
  - 진행하던 방향을 활용하여 학습을 효율적으로 진행

- **RMSProp (Root Mean Square Propagation)**
  - 최근 Gradient의 크기를 고려하여 파라미터별 업데이트 크기를 조절
  - Gradient가 큰 방향의 업데이트는 줄이고, 작은 방향은 상대적으로 크게 조정하여 안정적인 학습을 도움

- **Adam (Adaptive Moment Estimation)**
  - 딥러닝에서 널리 사용되는 Optimizer
  - Momentum과 RMSProp의 아이디어를 결합
  - 진행 방향의 관성과 Gradient의 크기를 함께 고려하여 가중치를 업데이트

---

### 7. Backpropagation (역전파)

> 경사하강법/Optimizer와 함께 등장하지만 **같은 개념은 아님**

**Backpropagation(역전파)** 은 신경망에서 예측값과 실제값의 차이로부터 각 파라미터가 Loss에 얼마나 영향을 주었는지 **Gradient를 뒤쪽 층에서 앞쪽 층 방향으로 계산하는 방법**이다.

```text
예측
 ↓
Loss 계산
 ↓
Backpropagation
 → 각 가중치의 Gradient 계산
 ↓
Optimizer
 → Gradient를 이용해 가중치 업데이트
```

즉,

- **Backpropagation** → Gradient를 계산
- **Optimizer** → 계산된 Gradient를 이용하여 가중치를 업데이트

---

### 8. 학습 반복

모델은 위 과정을 한 번만 수행하는 것이 아니라 반복하면서 점차 Loss를 줄여간다.

```text
예측
 ↓
Loss 계산
 ↓
Gradient 계산
 ↓
가중치 업데이트
 ↓
다시 예측
 ↓
...
```

이 과정을 반복하면서 모델의 `w`, `b`가 점차 더 적절한 값으로 조정된다.

### 9. Learning Rate (학습률)

Learning Rate는 가중치를 업데이트할 때 **한 번에 얼마나 이동할지를 결정하는 값**, 즉 경사하강법에서 **보폭을 조절하는 역할**을 한다.

```text
α = Learning Rate
```

- **학습률이 너무 큰 경우**
  - 최저점을 지나쳐버리는 **Overshooting**이 발생할 수 있음
  - 심한 경우 Loss가 줄어들지 않고 오히려 커지면서 **발산(Divergence)** 할 수 있음

- **학습률이 너무 작은 경우**
  - 한 번에 이동하는 보폭이 너무 작아 최저점까지 도달하는 데 오래 걸림
  - 정해진 학습 횟수 안에 충분히 최적화되지 못하고 학습이 끝날 수 있음

> **Learning Rate = 최저점을 찾아가는 보폭 조절**

### Model Parameter vs Hyperparameter

- **Model Parameter (모델 파라미터)**
  - 인공지능 모델이 훈련 과정을 통해 **스스로 학습하고 결정하는 값**
  - 예: 가중치(`w`), 편향(`b`)

- **Hyperparameter (하이퍼파라미터)**
  - 학습을 시작하기 전에 **사람이 미리 설정하는 값**
  - 예: 학습률(Learning Rate), 학습 횟수(Epoch)

```text
Model Parameter
→ 모델이 학습하면서 결정
→ Weight(w), Bias(b)

Hyperparameter
→ 사람이 학습 전에 설정
→ Learning Rate, Epoch
```

> **모델 파라미터 = 모델이 학습하는 값**  
> **하이퍼파라미터 = 사람이 학습 전에 설정하는 값**

### 실습: MinMaxScaler `ValueError`

#### 📌 문제 상황

`Price` 데이터를 `MinMaxScaler`로 스케일링하는 과정에서 `ValueError`가 발생했다.

```python
y = df2['Price']
y_scaled = scaler_y.fit_transform(y).flatten()
```

#### 🔍 원인

`df2['Price']`는 **1차원 Series**를 반환하지만, `MinMaxScaler.fit_transform()`은 `(행, 특성)` 형태의 **2차원 데이터**를 입력으로 기대한다.

| 선택 방법 | 반환 형태 | 차원 |
|---|---|---|
| `df['Price']` | Series | 1D `(n,)` |
| `df[['Price']]` | DataFrame | 2D `(n, 1)` |

```text
df2['Price']
→ Series
→ 1차원 (n,)
→ MinMaxScaler 입력 형태와 불일치
→ ValueError
```

#### ✅ 해결

`Price`를 처음부터 DataFrame 형태로 가져오도록 수정했다.

```python
y = df2[['Price']]

scaler_y = MinMaxScaler()
y_scaled = scaler_y.fit_transform(y).flatten()
```

`df2[['Price']]`처럼 **대괄호를 두 번 사용하면 하나의 열만 선택하더라도 2차원 DataFrame 형태가 유지**된다.

이미 Series로 가져왔다면 다음과 같이 변환할 수도 있다.

```python
# reshape 사용
y_2d = y.values.reshape(-1, 1)

# 또는 DataFrame으로 변환
y_df = y.to_frame()
```

> `reshape(-1, 1)`에서 `-1`은 데이터 개수에 맞춰 행의 수를 자동으로 계산하고, `1`은 열을 하나로 만든다는 의미이다.

#### 💡 배운 점

- `df['column']` → **Series (1D)**
- `df[['column']]` → **DataFrame (2D)**
- `MinMaxScaler`와 같은 scikit-learn의 전처리 Transformer는 일반적으로 `(n_samples, n_features)` 형태의 **2차원 입력**을 사용한다.
- 머신러닝에서는 값뿐만 아니라 **데이터의 형태(shape)와 차원(ndim)**도 확인해야 한다.

```python
print(y.shape)
print(y.ndim)
```

→ 이번 실습을 통해 **같은 컬럼이라도 데이터를 선택하는 방법에 따라 차원이 달라지며, 라이브러리가 요구하는 입력 형태에 맞춰 데이터를 전달해야 한다는 점**을 배웠다.

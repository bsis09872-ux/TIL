### 1. 다중 선형회귀 (Multiple Linear Regression)

데이터를 불러온 후 `X`와 `y`를 원하는 차원으로 정의하고 선형회귀 모델을 학습한다.

```python
import sklearn
import pandas as pd

sklearn.set_config(display='text')

df = pd.read_csv("usa_housing.csv")
```

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X, y)
```

모델 학습 후 가중치와 절편을 확인할 수 있다.

```text
가중치: [17.64218384 165.54335017 2753.89459814]
절편: 446703.79143559677
```

특성이 여러 개라면 가중치도 특성의 개수만큼 존재한다.

```text
y = 17x₁ + 165x₂ + 2753x₃ + 446703

x₁ = 면적
x₂ = 범죄율
x₃ = 학군
y  = 집값
```

> 여러 개의 독립변수 `x₁, x₂, x₃ ...`를 사용하는 것은 **다중회귀(Multiple Regression)**이다.  
> **다항회귀(Polynomial Regression)**는 `x²`, `x³` 등 다항식 형태의 특성을 사용하는 회귀이다.

### 2. Feature Scaling

각 독립변수의 단위와 값의 범위가 다르면 **가중치의 크기만으로 영향력을 단순 비교하기 어렵다.**

따라서 특성들의 기준을 맞추기 위해 **스케일링(Scaling)**을 사용할 수 있다.

| 방법 | 핵심 | 결과 |
|---|---|---|
| Min-Max Scaling | 최소값과 최대값을 기준으로 변환 | 보통 `0 ~ 1` |
| Standardization | 평균과 표준편차를 기준으로 변환 | 평균 `0`, 표준편차 `1` |

#### Min-Max Scaling

```text
X_new = (X - min) / (max - min)
```

#### Standardization (Z-score)

```text
X_new = (X - mean) / std
```

전체 표본에서 평균을 뺀 값을 표준편차로 나눈다.

```python
from sklearn.preprocessing import MinMaxScaler, StandardScaler
```

#### MinMaxScaler 실습

```python
min_max_scaler = MinMaxScaler()

min_max_scaler.fit(X.values)  # 준비(기준)
X_scaled1 = min_max_scaler.transform(X.values)  # 변환(0~1)

X_scaled1[:10]
```

이번 실습에서는 학습을 위해 `fit()`과 `transform()`을 따로 실행했지만, `fit_transform()`으로 한 번에 처리할 수도 있다.

```python
X_scaled1 = min_max_scaler.fit_transform(X.values)
```

StandardScaler도 동일하다.

```python
ss = StandardScaler()

# ss.fit(X_sqft)
# X_scaled = ss.transform(X_sqft)

X_scaled = ss.fit_transform(X_sqft)

X_scaled[:10]
```

> `.values`는 Pandas의 데이터를 NumPy 배열 형태로 가져온다. scikit-learn에서는 DataFrame을 직접 받을 수 있는 경우도 많기 때문에 항상 `.values`로 바꿔야 하는 것은 아니며, 이번에는 학습을 위해 변환해 보았다.

### 3. 데이터 분리: Train / Validation / Test

모델 학습과 평가를 위해 데이터를 용도에 따라 나눈다.

| 데이터 | 역할 |
|---|---|
| **학습 세트 (Train Set)** | 모델이 직접 학습하는 데이터 |
| **검증 세트 (Validation Set)** | 학습 과정에서 모델 및 하이퍼파라미터 평가·조정 |
| **테스트 세트 (Test Set)** | 학습이 모두 끝난 후 최종 성능 평가 |

Validation Set에서는 학습 과정의 `Loss` 등을 확인하여 모델의 상태를 평가할 수 있다.

> Test Set은 가중치를 조정하기 위한 데이터가 아니라 **최종 성능 확인용 데이터**이다.

`stratify=`는 주로 **분류 문제에서 클래스의 비율을 Train/Test 등에 비슷하게 유지하며 데이터를 나눌 때** 사용한다.

---

### 4. 모델 학습 과정의 핵심

> **예측 → 손실 계산 → 기울기 계산 → 가중치 업데이트 → 반복**

| 단계 | 용어 | 의미 |
|---|---|---|
| 1 | **순전파 (Forward Pass)** | 입력 데이터로 예측값 생성 |
| 2 | **손실 계산 (Loss Calculation)** | 예측값과 실제값의 차이를 수치화 |
| 3 | **역전파 (Backpropagation)** | 미분을 통해 각 파라미터의 기울기(Gradient) 계산 |
| 4 | **옵티마이저 (Optimizer)** | 기울기를 바탕으로 파라미터를 어떻게 업데이트할지 결정 |
| 5 | **가중치 갱신 (Weight Update)** | 새로운 가중치로 갱신하고 다음 학습 반복 |

> 역전파(Backpropagation)는 주로 신경망에서 Gradient를 효율적으로 계산하는 방법이다. 선형회귀의 경사하강법에서도 핵심 원리는 **Loss의 Gradient를 계산하여 파라미터를 업데이트하는 것**이다.

---

### 5. 경사하강법과 Learning Rate

**경사하강법(Gradient Descent)**은 Loss가 작아지는 방향으로 가중치를 반복해서 조정하는 방법이다.

Learning Rate는 한 번의 업데이트에서 **얼마나 이동할지 결정하는 보폭**이다.

```text
학습률이 너무 큼
→ 최저점을 지나침 (Overshooting)
→ 반대편으로 넘어가며 진동하거나 발산할 수 있음

학습률이 너무 작음
→ 최저점까지 이동하는 데 너무 오래 걸림

적절한 학습률
→ Loss가 안정적으로 감소
```

일반적으로 `0.01`, `0.001` 등의 값을 시작점으로 사용할 수 있지만 적절한 값은 문제와 모델에 따라 달라진다.

---

### 6. Optimizer

**Optimizer = 가중치를 어떻게 업데이트할지 결정하는 알고리즘**

| Optimizer | 핵심 |
|---|---|
| SGD | 기본적인 확률적 경사하강법 |
| Momentum | 이전 업데이트 방향의 관성을 활용 |
| RMSProp | Gradient 크기에 따라 학습률을 조절 |
| Adam | Momentum과 적응적 학습률 조정의 장점을 결합 |

> Adam은 딥러닝에서 널리 사용되지만 항상 가장 좋은 Optimizer라는 의미는 아니다.

---

### 7. Underfitting vs Overfitting

#### 과소적합 (Underfitting)

모델이 데이터의 패턴을 **충분히 학습하지 못한 상태**이다.

#### 과대적합 (Overfitting)

Train 데이터에는 지나치게 잘 맞지만 **새로운 데이터에 대한 일반화 성능이 떨어지는 상태**이다.

```text
Underfitting
→ 학습 부족 / 모델이 너무 단순

적절한 학습
→ Train과 Validation 모두 적절한 성능

Overfitting
→ Train 성능은 계속 좋아질 수 있지만
→ Validation Loss가 다시 증가할 수 있음
```

- **Convergence(수렴)**: 학습이 진행되면서 Loss나 파라미터의 변화가 점차 작아져 안정되는 것
- **Generalization(일반화)**: 학습하지 않은 새로운 데이터에서도 좋은 성능을 내는 것

> `Convergence = 적절한 학습`은 아니다. 모델이 수렴했더라도 Overfitting될 수 있으므로 **Validation 성능을 함께 확인**해야 한다.

Validation Loss가 더 이상 개선되지 않는 경우 학습을 종료하는 **Early Stopping**을 사용할 수 있다.

---

### 8. 다중회귀와 다중공선성

**다중공선성(Multicollinearity)**은 독립변수들 사이에 강한 선형 관계가 존재하여 서로 비슷한 정보를 가지고 있는 상태이다.

이 경우 개별 가중치의 추정이 불안정해지고 각 변수의 영향력을 해석하기 어려워질 수 있다.

> 다중공선성은 특히 **회귀계수의 안정성과 해석**에 문제가 된다. 과대적합과 관련될 수 있지만 `다중공선성 = 과대적합`은 아니다.

---

### 9. 규제 (Regularization)

**Regularization(규제)**은 모델이 지나치게 복잡해지는 것을 막아 **Overfitting을 완화하는 방법**이다.

> ⚠️ `Regularization`과 `Normalization`은 다른 개념이다.
>
> - **Normalization / Scaling** → 입력 데이터의 값 범위를 조정
> - **Regularization** → 모델의 가중치나 복잡도를 제한

Overfitting에 대한 대표적인 대응 방법은 다음과 같다.

1. 모델 단순화
2. Regularization
   - L1: Lasso
   - L2: Ridge
   - Dropout (신경망)
3. Data Augmentation
4. Early Stopping

> **규제의 핵심:** Loss에 가중치에 대한 페널티를 추가하여 지나치게 큰 가중치를 억제한다.

---

### 10. L1 규제: Lasso

**Lasso = Least Absolute Shrinkage and Selection Operator**

```text
Loss_Lasso = MSE + α × Σ|w|
```

모든 가중치의 **절댓값**을 이용해 페널티를 부여한다.

→ 가중치를 작게 만들도록 유도  
→ 일부 가중치는 **정확히 0**이 될 수 있음  
→ 해당 특성이 예측에 기여하지 않게 되어 **Feature Selection 효과**가 발생

#### Feature Selection

**Feature Selection(특성 선택)**은 여러 특성 중 예측에 필요한 특성을 선택하고 불필요한 특성의 영향을 제거하는 과정이다.

```text
중요한 특성 → 가중치가 남음

덜 필요한 특성 → 가중치가 0이 될 수 있음
                       ↓
                  예측에 영향 X
                       ↓
              Feature Selection 효과
```

> 데이터의 컬럼 자체를 삭제하는 것은 아니며, **가중치를 0으로 만들어 모델에서 사실상 사용하지 않는 효과**를 만든다.

- **장점:** 모델이 단순해지고 중요한 특성을 해석하기 쉬워질 수 있음
- **주의:** 서로 강하게 연관된 특성이 많으면 그중 일부만 선택하는 등 선택 결과가 불안정할 수 있음

---

### 11. L2 규제: Ridge

```text
Loss_Ridge = MSE + α × Σw²
```

Ridge는 **가중치가 지나치게 커지는 것을 막는 방식**이다.

쉽게 생각하면 가중치마다 **"너무 커지면 벌점!"**이라는 규칙을 추가하는 것이다.

```text
가중치가 큼
→ 제곱하면 벌점이 훨씬 커짐
→ "이 가중치를 줄여야겠다"
→ 더 많이 줄이는 방향으로 학습

가중치가 작음
→ 벌점도 작음
→ 상대적으로 적게 조정
```

즉, **특정 특성 하나에 모델이 지나치게 의존하지 않도록 가중치들을 눌러주는 역할**을 한다.

> Lasso는 일부 가중치를 `0`으로 만들 수 있지만, Ridge는 일반적으로 가중치를 **0에 가깝게 줄이되 완전히 0으로 만들지는 않는다.**

#### L2 규제항

```text
규제항 = w₁² + w₂² + w₃² + ... + wₚ²
```

일반적인 Ridge에서는 **편향(Intercept) `b`는 규제 대상에서 제외**한다.

```text
가중치 w → 규제 O → 특성의 영향력 통제
편향 b   → 규제 X → 모델의 기본적인 위치 조정
```

---

### 12. 규제 강도 α

규제식의 `α`는 **규제를 얼마나 강하게 적용할지를 사람이 정하는 하이퍼파라미터**이다.

```text
α가 큼
→ "가중치가 커지면 벌점을 세게 줘!"
→ 가중치를 더 많이 줄임
→ 더 단순한 모델

α가 작음
→ "벌점을 약하게 줘."
→ 가중치를 비교적 많이 유지
→ 규제 효과가 약함
```

> 너무 강한 규제는 모델을 지나치게 단순하게 만들어 **Underfitting**을 일으킬 수 있다.

또한 여기의 `α`는 경사하강법에서 사용했던 **Learning Rate와 다른 값**이다.

```text
Learning Rate의 α
→ 한 번에 이동하는 보폭

Regularization의 α
→ 가중치에 주는 벌점의 강도
```

#### 규제가 강하면 Loss가 커진다는 의미

규제를 적용한 모델의 전체 목적함수는 단순한 예측 오차만 보는 것이 아니다.

```text
전체 Loss = 예측 Loss + 규제 Penalty
```

따라서 규제를 강하게 하면 페널티의 영향이 커진다.

이는 무조건 나쁜 것이 아니라 **예측 오차를 조금 감수하더라도 지나치게 큰 가중치를 억제하여 더 단순하고 일반화 가능한 모델을 만들기 위한 대가**이다.

---

### 13. Ridge vs Lasso

규제가 가중치를 제한하는 모양을 기하학적으로 보면 다음과 같은 차이가 있다.

```text
Ridge
→ 둥근 형태의 제약
→ 가중치가 0에 가까워지지만 정확히 0이 되기는 어려움

Lasso
→ 모서리가 있는 형태의 제약
→ 축 위에서 최적점이 결정될 수 있음
→ 일부 가중치가 정확히 0이 될 수 있음
```

따라서 Lasso에서는 **Feature Selection 효과**가 나타날 수 있다.

---

### 14. Feature Engineering

**특성 공학(Feature Engineering)**은 기존 특성을 변환하거나 조합하여 모델 학습에 도움이 되는 새로운 특성을 만드는 과정이다.

```text
기존 Feature
→ 변환 / 조합
→ 새로운 Feature
```

특성을 무조건 많이 만드는 것이 좋은 것은 아니다. 불필요한 특성이 많아지면 모델의 복잡도가 증가하고 과대적합 위험도 커질 수 있으므로 적절하게 구성해야 한다.

> **상호작용항(Interaction Term)을 만드는 것도 Feature Engineering의 한 방법이 될 수 있다.**

예를 들어 `x₁ × x₂`라는 새로운 특성을 만들어 모델에 넣으면 두 특성이 함께 변할 때의 관계를 모델링할 수 있다.

| **⑨ Feature Engineering** | 모델에 사용할 특성 개선 |

> **Scaler = 입력 데이터의 크기 조정**  
> **Optimizer / Learning Rate = 모델의 학습 과정 조정**  
> **Regularization = 모델의 가중치와 복잡도 제어**  
> **Feature Engineering = 모델에 입력할 특성 개선**

### 경사하강법 Loop 실습

실습을 통해 모델이 한 번에 완성되는 것이 아니라 다음 과정을 반복하며 학습한다는 것을 확인했다.

```text
예측
→ Loss 계산
→ Gradient 계산
→ 가중치 업데이트
→ 다시 예측
→ 반복
```

#### 실습에서 배운 개념

1. **과소적합(Underfitting)**: 모델이 데이터의 패턴을 충분히 학습하지 못한 상태
2. **과대적합(Overfitting)**: Train 데이터에는 잘 맞지만 새로운 데이터에 대한 성능이 떨어지는 상태
3. **수렴(Convergence)**: 학습이 진행되면서 Loss나 파라미터의 변화가 점차 작아지는 상태
4. **조기 종료(Early Stopping)**: Validation Loss가 더 이상 개선되지 않을 때 학습을 종료하는 방법

> 학습을 무조건 오래 하는 것이 좋은 것이 아니라, **Validation Loss를 확인하면서 새로운 데이터에서도 잘 작동하는 지점을 찾는 것이 중요하다.**

### 오늘의 핵심

> **모델 학습 = Loss가 작아지도록 파라미터를 반복적으로 조정하는 과정**

하지만 Train Loss만 낮추는 것이 최종 목적은 아니다. **새로운 데이터에서도 잘 예측하는 일반화(Generalization) 성능**을 확보하는 것이 중요하다.

이를 위해 **Scaling → Data Split → 학습 → Validation → Regularization** 등의 방법을 연결하여 사용한다.

### Daily Quest

1. **Train / Valid / Test 분리**
   - 정답: **과적합 방지 및 일반화 성능 검증**
   - 학습에 사용하지 않은 데이터로 모델의 실제 성능을 확인하기 위함.

2. **Overshooting**
   - 정답: **최적점을 지나쳐버리는 현상**
   - 큰 학습률이나 데이터 스케일이 원인이 될 수 있음.

3. **`random_state=42`**
   - 정답: **동일한 데이터 분할 결과를 재현하기 위해**
   - `random_state` → 재현성
   - `stratify` → 클래스 비율 유지

4. **Ridge vs Lasso**
   - **Ridge(L2)**: 가중치를 전반적으로 축소
   - **Lasso(L1)**: 일부 가중치를 `0`으로 만들어 **특성 선택 효과** 가능

5. **다중공선성(Multicollinearity)**
   - 정답: **독립변수 간 높은 상관관계로 각 변수의 기여도를 구분하기 어려운 현상**
   - `VIF ≥ 10`은 심각한 다중공선성을 판단할 때 사용하는 경험적 기준 중 하나.

# REVIEW

## 적응적 학습률과 Optimizer

**RMSProp**은 최근 Gradient의 크기를 반영하여 **파라미터별 학습률을 적응적으로 조절**한다.

- 최근 Gradient가 큰 방향 → 업데이트 크기를 상대적으로 줄여 진동 완화
- 최근 Gradient가 작은 방향 → 업데이트가 지나치게 작아지지 않도록 조절

| Optimizer | 핵심 |
|---|---|
| **SGD** | 기본적인 경사하강 기반 업데이트 |
| **Momentum** | 이전 진행 방향의 관성을 활용 |
| **RMSProp** | 파라미터별 적응적 학습률 |
| **Adam** | 관성 + 적응적 학습률 |

> 실무에서는 **Adam을 좋은 기본 선택지로 많이 사용**하지만, 항상 최고의 Optimizer인 것은 아니다.

# LECTURE NOTE

## 1. Regression vs Classification

머신러닝의 주요 예측 문제는 크게 두 가지로 나눌 수 있다.

```text
Machine Learning
      │
      ├── Regression
      │      └── 연속적인 숫자 예측
      │
      └── Classification
             └── 어떤 범주(Class)에 속하는지 예측
```

**로지스틱 회귀(Logistic Regression)**는 이름에 `Regression`이 들어가지만 실제 목적은 **분류(Classification)**이다.

### [참고] 주요 분류 모델

| 모델 | 특징 |
|---|---|
| Logistic Regression | 선형 결정경계, 빠르고 간단 |
| Decision Tree | 비선형 관계 표현, 해석 쉬움 |
| Random Forest | 여러 트리를 결합하여 안정성 향상 |
| SVM | 고차원 데이터에서도 활용 |
| KNN | 단순하지만 예측 시 계산량 증가 가능 |
| Neural Network | 복잡한 패턴 학습 가능 |

# 2. 이진 분류 (Binary Classification)

## 2-1. 이진 분류란?

**두 개의 클래스 중 하나를 예측하는 문제**이다.

### 실습: 붓꽃 분류

- **X (특성):** 꽃잎 너비, 꽃잎 길이
- **y (정답):** Setosa, Versicolor

두 가지 종류 중 하나를 선택하므로 **이진 분류**이다.

> **Class:** 분류 문제에서 가능한 범주 또는 선택지

```text
Positive = 1
Negative = 0
```

Positive와 Negative는 좋고 나쁨의 의미가 아니라 **어떤 클래스를 `1`과 `0`으로 정의했는지에 따른 구분**이다.

---

## 2-2. Logit

입력 특성과 가중치를 선형 결합한다.

```text
z = w₁x₁ + w₂x₂ + ... + b
```

- `x` : 입력 특성
- `w` : 가중치
- `b` : 편향
- `z` : 확률로 변환하기 전의 원시 점수(Logit)

초기에는 임의의 가중치와 편향으로 시작하고, 학습하면서 손실을 줄이는 방향으로 업데이트된다.

---

## 2-3. 활성화 함수: Sigmoid

Logit `z`를 **0~1 사이의 확률값**으로 변환한다.

```text
Sigmoid(z) = 1 / (1 + e^(-z))
```

여기서 `e`는 약 `2.718`인 **자연상수**이다.

지금 단계에서는 `e` 자체보다 **Sigmoid가 어떤 크기의 z값도 0~1 사이로 바꿔준다는 것**이 중요하다.

```text
z가 큰 양수 → 1에 가까움
z = 0       → 0.5
z가 큰 음수 → 0에 가까움
```

예:

```text
Logit z
   ↓
Sigmoid
   ↓
0.8
   ↓
Class 1일 확률 80%
```

이후 기준값(예: `0.5`)을 이용하여 최종 클래스를 결정할 수 있다.

---

## 2-4. 손실함수: BCE

**BCE(Binary Cross Entropy)**는 실제 정답과 모델의 예측 확률을 이용해 이진 분류의 손실을 계산한다.

> **틀린 예측에 벌점을 주며, 특히 틀린 답을 강하게 확신할수록 더 큰 벌점을 준다.**

```text
실제 정답 = 1

예측 0.9 → 거의 맞음 → Loss 작음
예측 0.5 → 애매함   → Loss 중간
예측 0.1 → 크게 틀림 → Loss 큼
```

공식:

```text
BCE = -[y log(ŷ) + (1-y)log(1-ŷ)]
```

- `y` : 실제 정답 (`0` 또는 `1`)
- `ŷ` : 모델의 예측 확률 (`0~1`)

정답에 따라 계산되는 부분은 다음과 같다.

```text
y = 1 → Loss = -log(ŷ)
y = 0 → Loss = -log(1-ŷ)
```

즉,

```text
정답에 높은 확률 → Loss ↓
틀린 답에 높은 확률 → Loss ↑
```

> **이진 분류 핵심: `Logit → Sigmoid → 확률 → BCE`**

### 실습 도구

```python
import numpy as np
import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score
```

이번 실습에서는 별도의 스케일링 없이 진행했다.

# 3. 다중 분류 (Multi-Class Classification)

## 3-1. 다중 분류란?

**3개 이상의 클래스 중 하나를 예측하는 문제**이다.

붓꽃 전체 3종류를 분류한다면:

```text
Setosa
Versicolor
Virginica
```

→ **다중 분류**

---

## 3-2. 클래스별 Logit

다중 분류에서는 **각 클래스에 대한 Logit**을 계산한다.

```text
Class 0 → z₀
Class 1 → z₁
Class 2 → z₂
```

각 클래스는 자신의 가중치와 편향을 가진다.

```text
z₀ = w₀ᵀx + b₀
z₁ = w₁ᵀx + b₁
z₂ = w₂ᵀx + b₂
```

---

## 3-3. 활성화 함수: Softmax

Softmax는 여러 Logit을 **각 클래스의 확률**로 변환한다.

```text
P(Class k) = e^(zₖ) / Σe^(zⱼ)
```

예:

```text
각 클래스의 Logit
       ↓
    Softmax
       ↓
Setosa      → 0.10
Versicolor  → 0.70
Virginica   → 0.20
              ────
확률 합계      1.00
```

가장 높은 확률의 클래스를 최종 예측으로 선택할 수 있다.

---

## 3-4. One-Hot Encoding

다중 분류의 정답을 표현하는 방법 중 하나이다.

```text
정수 Label       One-Hot

0          →    [1, 0, 0]
1          →    [0, 1, 0]
2          →    [0, 0, 1]
```

각 클래스를 독립된 위치로 표현하여 `0 < 1 < 2`와 같은 **수치적 순서의 의미를 부여하지 않는다.**

클래스가 매우 많아지면 벡터가 커지고 대부분의 값이 `0`이 되어 **메모리 사용량이 증가**할 수 있다.

> 다중 분류에서 One-Hot Encoding이 항상 필요한 것은 아니며, 정수 Label을 그대로 사용할 수도 있다.

---

## 3-5. 다중 분류의 손실함수

### CCE (Categorical Cross Entropy)

정답을 **One-Hot 형태**로 전달한다.

```text
정답 → [0, 1, 0]
예측 → [0.1, 0.7, 0.2]
```

```text
Loss = -Σ yₖ log(ŷₖ)
```

One-Hot에서는 정답 클래스만 `1`이므로 **정답 클래스에 얼마나 높은 확률을 주었는지**가 손실을 결정한다.

### SCCE (Sparse Categorical Cross Entropy)

One-Hot 대신 **정수 클래스 번호**를 사용한다.

```text
CCE  → [0, 0, 1]
SCCE → 2
```

```text
Loss = -log(ŷ_target)
```

| 구분 | CCE | SCCE |
|---|---|---|
| 정답 형태 | One-Hot | Integer |
| 예 | `[0,0,1]` | `2` |
| 메모리 | 클래스가 많으면 증가 | 상대적으로 효율적 |
| 핵심 계산 | 정답 클래스의 확률 평가 | 동일 |

> **CCE와 SCCE는 같은 Cross Entropy 원리를 사용하며, 가장 큰 차이는 정답 Label의 표현 방식이다.**

※ 라이브러리마다 함수명과 Label 처리 방식에는 차이가 있다.

### [참고] Embedding

**Embedding**은 범주나 토큰을 저차원의 밀집 실수 벡터(Dense Vector)로 표현하는 방법으로, CCE/SCCE를 대체하는 손실함수는 아니다.

> **다중 분류 핵심: `여러 Logit → Softmax → 클래스별 확률 → CCE/SCCE`**

# 4. 이진 분류 vs 다중 분류

오늘 실습의 **두 가지 큰 축**을 비교하면 다음과 같다.

| 구분 | 이진 분류 | 다중 분류 |
|---|---|---|
| 클래스 | 2개 | 3개 이상 |
| 예 | Setosa / Versicolor | Setosa / Versicolor / Virginica |
| 원시 점수 | Logit | 클래스별 Logit |
| 확률 변환 | **Sigmoid** | **Softmax** |
| 출력 | Class 1의 확률 | 각 클래스의 확률 |
| 손실함수 | **BCE** | **CCE / SCCE** |
| 정답 표현 | 0 / 1 | One-Hot 또는 Integer |

> 공통 원리: **Logit 계산 → 확률 변환 → Loss 계산 → 가중치 업데이트**

# 5. K-Fold 교차검증 (Cross Validation)

한 번의 데이터 분할만으로 모델을 평가하면 **어떤 데이터가 평가용으로 선택되었는지에 따라 결과가 달라질 수 있다.**

K-Fold는 데이터를 `K`개의 조각(Fold)으로 나누어 반복적으로 평가한다.

```text
K = 5

1회  [Valid][Train][Train][Train][Train]
2회  [Train][Valid][Train][Train][Train]
3회  [Train][Train][Valid][Train][Train]
4회  [Train][Train][Train][Valid][Train]
5회  [Train][Train][Train][Train][Valid]

→ 5번의 평가 결과를 종합
```

> **목적:** 특정 데이터 분할의 우연에 덜 의존하는 모델 성능을 확인한다.

### 실습 도구

```python
from sklearn.model_selection import KFold, cross_val_score
```

최종 Test Set을 별도로 사용하는 경우:

```text
전체 데이터
    │
    ├── Train
    │      └── K-Fold Cross Validation
    │
    └── Test
           └── 최종 성능 평가
```

분류 문제에서는 각 Fold의 클래스 비율을 유지하는 **StratifiedKFold**도 많이 사용한다.

# 6. [개념 확장] 신경망과 MLP

신경망은 크게 **입력층 → 은닉층 → 출력층**으로 구성된다.

```text
[ 입력층 Input Layer ]
x₁   x₂   x₃ ...
       │
       ▼
[ 은닉층 Hidden Layer ]
○   ○   ○   ○
       │
       ▼
[ 출력층 Output Layer ]
○   ○   ○
       │
       ▼
    예측 결과
```

| 구성 | 역할 |
|---|---|
| **입력층 (Input Layer)** | Feature `x` 입력 |
| **은닉층 (Hidden Layer)** | 가중합과 활성화 함수를 통해 특징 학습 |
| **출력층 (Output Layer)** | 최종 예측값 또는 클래스 확률 출력 |

### 다층 퍼셉트론 (MLP)

**MLP(Multi-Layer Perceptron)**는 하나 이상의 은닉층을 가지는 기본적인 신경망 구조이다. 단순한 선형 모델로 표현하기 어려운 **복잡한 비선형 패턴을 학습하기 위해 사용**한다.

```text
입력층 → 은닉층 → (은닉층 ...) → 출력층
```

각 뉴런에서는 기본적으로 다음 계산을 수행한다.

```text
입력값
  ↓
가중합 z = Σ(wx) + b
  ↓
활성화 함수
  ↓
다음 층으로 전달
```

즉, 은닉층을 거치면서 입력 데이터를 반복적으로 변환하여 **더 복잡한 특징과 비선형 관계를 학습**할 수 있다.

### 활성화 함수 (Activation Function)

은닉층에서는 가중합 `z = Σ(wx) + b`를 계산한 뒤 **활성화 함수**를 적용한다.

#### 1. 선형 → 비선형

활성화 함수의 중요한 역할은 모델에 **비선형성(Non-linearity)**을 추가하는 것이다.

```text
입력
 ↓
가중합 z = Σ(wx) + b     ← 선형 변환
 ↓
활성화 함수               ← 비선형성 추가
 ↓
다음 층
```

비선형 활성화 함수가 없다면 여러 은닉층을 쌓아도 결국 하나의 선형변환처럼 표현될 수 있다.

> **은닉층 + 비선형 활성화 함수 → 복잡한 비선형 패턴 학습 가능**

---

#### 2. Sigmoid와 Gradient Vanishing

Sigmoid는 입력값을 **0~1 사이의 값으로 압축**하는 활성화 함수이다.

```text
큰 음수 → 0에 가까움
0       → 0.5
큰 양수 → 1에 가까움
```

단, 정확히 `0`과 `1`이 되는 것이 아니라 **0과 1에 가까워진다.**

Sigmoid의 기울기는 최대 `0.25`이고, 입력값이 매우 크거나 작아 출력이 0 또는 1에 가까워질수록 **기울기가 0에 가까워진다.**

신경망의 역전파에서는 여러 층의 기울기가 연쇄적으로 곱해진다.

```text
출력층에서 역전파 시작
        ↓
작은 Gradient
        ↓
× 작은 Gradient
        ↓
× 작은 Gradient
        ↓
Gradient가 점점 작아짐
        ↓
앞쪽 은닉층의 Weight 업데이트가 매우 작아짐
        ↓
학습이 거의 진행되지 않음

= Gradient Vanishing
  기울기 소실 문제
```

즉, **Sigmoid를 깊은 은닉층에서 반복적으로 사용하면 기울기가 점점 작아져 앞쪽 층까지 학습 신호가 제대로 전달되지 않을 수 있다.**

### 그래서 ReLU

이러한 문제를 완화하기 위해 현대 신경망의 은닉층에서는 **ReLU** 계열의 활성화 함수를 많이 사용한다.

```text
MLP

입력층
  ↓
은닉층 → ReLU
  ↓
은닉층 → ReLU
  ↓
출력층 → 문제에 맞는 활성화 함수
```

| 위치 | 대표 활성화 함수 |
|---|---|
| 은닉층 | **ReLU** 등 |
| 이진 분류 출력층 | **Sigmoid** |
| 다중 분류 출력층 | **Softmax** |

> **핵심:** 활성화 함수는 신경망에 **비선형성**을 추가한다. Sigmoid는 0~1 사이로 값을 압축하지만 깊은 은닉층에서 반복 사용하면 **Gradient Vanishing**이 발생할 수 있어, 은닉층에서는 ReLU 계열을 많이 사용한다.

# 머신러닝 기초
오늘 머신러닝에 대해서 처음 배웠다.
처음에는 머신러닝이 그냥 데이터를 넣으면 컴퓨터가 알아서 결과를 내주는 건 줄 알았는데, 생각보다 과정이 있었다.

## 머신러닝이란?
쉽게 말하면 컴퓨터에게 데이터를 많이 보여주고, 데이터에서 규칙이나 패턴을 찾아서 새로운 데이터를 예측하게 하는 것이라고 이해했다.
- 예를 들어 공부시간과 시험점수 데이터를 많이 보여주면 컴퓨터가 공부시간과 점수의 관계를 찾아서 새로운 사람의 시험점수를 예측하는 식이다.

### 선형회귀
선형회귀는 데이터를 보고 가장 잘 맞는 선을 찾아서 값을 예측하는 방법이라고 배웠다.
- 예를 들어 공부시간이 늘어나면 시험점수도 올라가는 데이터를 가지고 있을 때, 그 관계를 이용해서 새로운 점수를 예측할 수 있다.
- 선형회귀를 배우는 이유는 머신러닝이 학습하는 기본적인 과정을 이해하기 위해서라고 생각했다.
### Loss
모델이 예측한 값이 실제 정답과 얼마나 다른지 나타내는 값이다.
- 예를 들어 실제 점수가 80점인데 모델이 50점이라고 예측하면 많이 틀린 것이기 때문에 Loss가 커진다.
- 반대로 실제 점수가 80점이고 79점이라고 예측하면 거의 맞았기 때문에 Loss가 작다.
- 그래서 머신러닝에서는 Loss를 작게 만드는 것이 중요하다.

### 가중치
모델이 데이터를 가지고 예측할 때 사용하는 값이다.
- 처음부터 좋은 가중치를 가지고 있는 것이 아니기 때문에 처음에는 예측을 틀릴 수 있다.
그래서 계속 가중치를 바꿔가면서 더 잘 맞도록 만든다.

### 미분
미분은 처음에는 그냥 어려운 수학이라고 생각했는데, 머신러닝에서는 가중치를 어느 방향으로 바꿔야 Loss가 작아지는지 알아내는 데 사용한다고 이해했다.

### 경사하강법
경사하강법은 Loss를 줄이기 위해 가중치를 조금씩 바꾸는 방법이다.
- 산에서 가장 낮은 곳을 찾는 것과 비슷하다고 생각하면 된다.
- 현재 위치에서 아래쪽 방향을 찾고 조금 이동하고, 다시 아래쪽을 찾는 것을 반복해서 가장 낮은 곳으로 가는 것이다.

### 옵티마이저
옵티마이저는 가중치를 어떻게 바꿀지 정하는 방법이다.
- SGD, Momentum, Adam 등 여러 종류가 있다.
- 목표는 모두 비슷하게 Loss를 줄이는 것인데, 가중치를 조절하는 방법이 조금씩 다르다.

# 오늘 배운 내용
전체적으로 보면
```
데이터를 넣는다
↓
모델이 예측한다
↓
얼마나 틀렸는지 Loss를 확인한다
↓
미분해서 어느 방향으로 바꿀지 알아본다
↓
옵티마이저가 가중치를 바꾼다
↓
다시 예측한다
```
- 이 과정을 계속 반복하면서 모델이 점점 더 잘 맞도록 학습한다는 것을 배웠다.
- 아직 수식은 어렵지만 "틀리면 확인하고 → 가중치를 바꾸고 → 다시 해본다"라고 생각하니까 머신러닝의 학습 과정이 조금 이해됐다.

# Review

## 1. K-Fold Cross Validation과 Shuffle

K-Fold Cross Validation은 전체 데이터를 `K`개의 Fold로 나눈 뒤, 하나의 Fold를 검증 데이터로 사용하고 나머지를 훈련 데이터로 사용하는 과정을 반복하는 방법이다.

데이터가 특정한 순서로 정렬되어 있는 경우 단순히 순서대로 Fold를 나누면 특정 Fold에 특정 클래스가 몰리는 등 데이터 분포가 불균형해질 수 있다.

따라서 `shuffle=True`를 사용하면 데이터를 섞은 뒤 Fold를 구성할 수 있다.

> 단, 분류 문제에서 각 Fold의 클래스 비율 자체를 비슷하게 유지하는 것이 목적이라면 일반 `KFold`보다 `StratifiedKFold`를 사용하는 것이 더 적절할 수 있다.

---

## 2. Perceptron

**Perceptron(퍼셉트론)**은 인공 신경망의 가장 기본적인 계산 단위 중 하나로, 생물학적 뉴런의 작동 방식에서 아이디어를 얻은 모델이다.

기본적으로 입력값에 가중치를 적용하고 편향을 더한 뒤 활성화 함수를 거쳐 출력을 만든다.

```text
z = wx + b
```

여러 개의 퍼셉트론 구조를 층으로 연결하면 **Multi-Layer Perceptron(MLP)**을 구성할 수 있고, 여러 은닉층을 사용하는 심층 신경망(DNN)으로 확장할 수 있다.

### 주의

퍼셉트론 자체를 Linear Regression이나 Logistic Regression과 완전히 동일한 모델이라고 보는 것은 정확하지 않다.

다만 이들 모델 모두 `z = wx + b`와 같은 선형 결합을 기본 계산으로 사용한다는 공통점이 있다.

# 4강 1장. PyTorch 기초 및 심층 신경망

## 1. 다층 퍼셉트론과 활성화 함수

신경망의 각 층에서는 입력에 가중치와 편향을 적용한다.

```text
z = wx + b
```

하지만 선형 변환만 여러 번 연결하면 층을 여러 개 쌓아도 전체적으로 하나의 선형 변환으로 표현할 수 있다.

따라서 은닉층 사이에 **비선형 활성화 함수(Activation Function)**를 추가하여 신경망이 복잡한 비선형 패턴을 학습할 수 있도록 한다.

---

## 2. Sigmoid와 Vanishing Gradient

Sigmoid 함수는 입력을 `0~1` 사이의 값으로 변환한다.

하지만 입력의 절댓값이 큰 영역에서는 기울기가 매우 작아진다. 심층 신경망에서는 역전파 과정에서 여러 층의 미분값이 반복해서 곱해지므로, 작은 값이 계속 곱해지면 앞쪽 층으로 전달되는 Gradient가 점점 작아질 수 있다.

이를 **Vanishing Gradient(기울기 소실)**라고 한다.

따라서 현대적인 신경망의 은닉층에서는 Sigmoid 대신 ReLU와 같은 활성화 함수가 많이 사용된다.

---

## 3. ReLU

ReLU(Rectified Linear Unit)는 다음과 같이 동작한다.

```text
ReLU(x) = max(0, x)
```

음수는 `0`으로 만들고 양수는 그대로 전달한다.

Sigmoid와 달리 양수 영역에서 기울기가 일정하기 때문에 심층 신경망에서 기울기 소실 문제를 완화하는 데 도움이 된다.

다만 음수 영역에서는 기울기가 `0`이기 때문에 뉴런이 계속 음수 영역에 머물면 학습이 제대로 이루어지지 않을 수 있다. 이를 **Dead ReLU** 문제라고 한다.

---

## 4. Dropout

Dropout은 **과적합(Overfitting)을 억제하기 위한 Regularization 기법** 중 하나이다.

학습 과정에서 일부 뉴런의 출력을 일정 확률로 랜덤하게 `0`으로 만든다.

예:

```python
nn.Dropout(p=0.3)
```

`0.2~0.5` 정도의 값이 자주 사용될 수 있지만, 적절한 비율은 모델과 데이터에 따라 달라지는 하이퍼파라미터이다.

### 중요한 점

Dropout은 **영향력이 큰 가중치만 골라서 끄는 것이 아니다.**

뉴런의 출력을 **랜덤하게** 비활성화한다. 이를 통해 특정 뉴런이나 특정 특징에 모델이 지나치게 의존하는 것을 줄이고, 여러 뉴런이 보다 분산된 방식으로 특징을 학습하도록 유도한다.

일반적으로:

- Training → Dropout 사용
- Evaluation / Test → Dropout 비활성화

PyTorch에서는 `model.train()`에서 Dropout이 활성화되고 `model.eval()`에서 비활성화된다.

---

## 5. 신경망 학습의 4단계 순환 구조

신경망 학습은 크게 다음 과정을 반복한다.

```text
① Forward Propagation
        ↓
② Loss Calculation
        ↓
③ Backpropagation → Gradient 계산
        ↓
④ Optimizer → Weight Update
        ↓
다음 Epoch에서 반복
```

### ① Forward Propagation

입력 데이터를 신경망에 통과시켜 예측값을 계산한다.

### ② Loss Calculation

모델의 예측과 실제 정답 `y`를 비교하여 얼마나 틀렸는지를 계산한다.

### ③ Backpropagation

Loss를 기준으로 각 가중치가 Loss에 얼마나 영향을 주었는지 Gradient를 계산한다.

### ④ Optimizer

계산된 Gradient를 이용하여 Loss가 감소하는 방향으로 가중치를 업데이트한다.

대표적으로 `SGD`, `Adam` 등이 있으며 실제 딥러닝에서는 **Adam Optimizer**가 자주 사용된다.

---

## 6. Epoch

Epoch는 **전체 Training Dataset을 한 번 학습하는 단위**이다.

각 Epoch에서 여러 batch를 거치며 Forward → Loss → Backpropagation → Weight Update 과정이 반복된다.

---

## 7. Underfitting과 Overfitting

### Underfitting — 과소적합

모델이 데이터의 패턴을 충분히 학습하지 못한 상태이다.

대표적으로 **Training Loss와 Validation Loss가 모두 높은 경향**을 보일 수 있다.

모델이 너무 단순하거나 학습이 충분하지 않은 경우 발생할 수 있으며, 은닉층이나 뉴런 수를 늘려 모델의 Capacity를 키우거나 Epoch를 늘리는 등의 방법을 고려할 수 있다.

### Overfitting — 과적합

모델이 Training Data의 일반적인 패턴뿐만 아니라 노이즈나 지나치게 세부적인 특징까지 학습한 상태이다.

**Training Loss는 계속 감소하지만 Validation Loss는 감소하다 다시 증가하는 경향**이 나타날 수 있다.

Dropout 등의 Regularization 기법을 이용하여 이를 완화할 수 있다.

---

## 8. 데이터 분할

데이터는 일반적으로 다음과 같이 구분한다.

- **Training Data:** 모델의 가중치 학습
- **Validation Data:** 모델 선택 및 Hyperparameter 조정
- **Test Data:** 최종 모델의 일반화 성능 평가

# 4강 2장. 순환 신경망 아키텍처 구현
## 1. RNN과 자연어 데이터

RNN(Recurrent Neural Network)은 순서가 중요한 Sequential Data를 처리하기 위한 신경망 구조이다.

자연어 역시 단어의 순서에 따라 의미가 달라지기 때문에 Sequence Data로 볼 수 있다.

예:

`나는 → 너를 → 사랑해`

신경망은 문자열 자체를 계산할 수 없기 때문에 각 단어 또는 Token을 숫자로 표현해야 한다.

전체 Token의 집합을 **Vocabulary(Vocab)**라고 하며, 각 Token에는 고유한 정수 Index를 부여할 수 있다.

예:

`0 → 나는`
`1 → 너를`
`2 → 사랑해`

이 숫자는 단어의 의미가 아니라 Token을 구분하기 위한 **Index**이다.

---

## 2. One-Hot Encoding과 Sparse Vector

One-Hot Encoding에서는 해당 Token의 위치만 `1`, 나머지를 `0`으로 표현한다.

예:

`나는   → [1, 0, 0]`
`너를   → [0, 1, 0]`
`사랑해 → [0, 0, 1]`

이처럼 대부분의 값이 `0`인 벡터를 **Sparse Vector(희소 벡터)**라고 한다.

One-Hot Encoding은 Vocabulary가 커질수록 벡터의 차원이 과도하게 커지며, Token 사이의 의미적 관계를 직접 표현하기 어렵다는 한계가 있다.

---

## 3. Embedding과 Dense Vector

Embedding은 Token을 **상대적으로 낮은 차원의 실수형 Dense Vector**로 표현하는 방법이다.

예:

`Vocabulary Size = 1,000`
`Embedding Dimension = 10`

One-Hot 방식에서는 하나의 Token을 1,000차원 Sparse Vector로 표현하지만, Embedding을 사용하면 하나의 Token을 10차원의 실수형 Dense Vector로 표현할 수 있다.

---

## 4. Embedding Weight Matrix

Embedding에는 학습 가능한 가중치 행렬 `W_emb`가 존재할 수 있다.

```text
Vocab Size = 1,000
Embedding Dimension = 10

W_emb shape = 1,000 × 10
```

`W_emb`의 각 행은 하나의 Token에 대응하는 10차원 Embedding Vector이다.

수학적으로 Embedding을 다음과 같이 이해할 수 있다.

```text
Embedding(w) = One-Hot(w) × W_emb = v_w
```

- `w`: 특정 Token
- `One-Hot(w)`: 해당 Token의 One-Hot Vector
- `W_emb`: Embedding Weight Matrix
- `v_w`: Token `w`의 Embedding Vector

예를 들어:

```text
W_emb

[0.1  0.2  0.3]  ← 나는
[0.7  0.8  0.9]  ← 너를
[0.4  0.5  0.6]  ← 사랑해
```

`"너를"`의 One-Hot Vector가 `[0, 1, 0]`이라면:

```text
Embedding("너를")
= [0, 1, 0] × W_emb
= [0.7, 0.8, 0.9]
```

가 된다.

즉, One-Hot Vector와 `W_emb`의 행렬곱은 **W_emb에서 해당 Token의 행을 선택하는 것과 같은 결과**를 만든다.

실제 구현에서는 거대한 One-Hot Vector를 직접 만들기보다 Token Index를 이용해 해당 Embedding Vector를 조회하는 방식으로 효율적으로 처리할 수 있다.

---

## 5. Embedding은 어떻게 학습되는가?

학습 가능한 Embedding을 처음부터 학습하는 경우 `W_emb`는 초기화된 값에서 시작할 수 있다.

모델이 예측을 수행하고 Loss를 계산한 뒤 Backpropagation을 수행하면 `W_emb` 역시 Gradient를 전달받는다. Optimizer가 이를 이용하여 Embedding Weight를 업데이트한다.

즉, **Embedding의 가중치 역시 모델의 Loss를 줄이는 방향으로 학습된다.**

# RNN의 Hidden State와 Time Step

## 1. RNN의 핵심 구조

RNN의 가장 중요한 특징은 이전 시점의 정보를 다음 시점의 계산에 다시 사용한다는 것이다.

```text
h_t = f(W_x x_t + W_h h_(t-1) + b)
```

- `x_t`: 현재 Time Step의 입력
- `h_(t-1)`: 이전 Time Step의 Hidden State
- `W_x`: 현재 입력에 적용되는 가중치
- `W_h`: 이전 Hidden State에 적용되는 순환 가중치
- `b`: Bias
- `h_t`: 현재의 새로운 Hidden State

즉,

> **현재 입력 + 이전까지의 상태 → 새로운 Hidden State**

라고 이해할 수 있다.

---

## 2. Hidden State

예를 들어 `"나는 → 너를 → 사랑해"`라는 Sequence를 처리한다면:

```text
t=1          t=2          t=3
나는         너를         사랑해
 ↓            ↓             ↓
RNN ─h1→    RNN ─h2→     RNN
```

`t=2`에서는 현재 입력 `"너를"`와 이전 Hidden State `h1`을 이용해 새로운 `h2`를 만든다.

중요한 것은 `h1`에 `"나는"`이라는 문자열 자체가 저장되고, `h2`에 `"나는 너를"`라는 문장이 그대로 저장되는 것은 아니라는 점이다.

**Hidden State는 지금까지 입력된 정보를 RNN이 숫자 벡터 형태로 요약하여 가지고 있는 상태**라고 이해하는 것이 정확하다.

---

## 3. Time Step과 Weight Sharing

Time Step은 Sequence를 처리하는 각각의 시점을 의미한다.

```text
나는      너를      사랑해
t=1       t=2       t=3
```

각 Time Step마다 완전히 새로운 RNN Layer를 생성하는 것은 아니다.

**같은 RNN 구조와 같은 가중치를 시간축을 따라 반복해서 사용한다.**

이를 **Weight Sharing**이라고 한다.

---

# RNN과 활성화 함수

## 1. BPTT

RNN에서는 동일한 순환 연산이 여러 Time Step에 걸쳐 반복된다.

학습 시에는 Loss를 기준으로 시간축을 거슬러 Gradient를 계산하는데, 이를 **BPTT(Backpropagation Through Time)**라고 한다.

이 과정에서 순환 가중치와 활성화 함수의 미분값이 반복적으로 영향을 주기 때문에 Gradient가 지나치게 커지거나 작아지는 문제가 발생할 수 있다.

---

## 2. Exploding Gradient와 ReLU

RNN에서는 시간축을 거슬러 Gradient를 계산하면서 순환 가중치가 반복적으로 영향을 미친다.

조건에 따라 Gradient의 크기가 반복적으로 증가하면 **Exploding Gradient(기울기 폭발)**가 발생할 수 있다.

ReLU는 양수 영역의 값을 위쪽으로 제한하지 않기 때문에 RNN의 반복 구조에서 이러한 불안정성을 제어하기 어려울 수 있다.

또한 ReLU는 음수 영역에서 Gradient가 `0`이다. 뉴런이 계속 음수 영역에 머무르면 학습이 어려워질 수 있으며 이를 **Dead ReLU**라고 한다.

---

## 3. tanh

기본적인 Vanilla RNN에서는 Hidden State의 활성화 함수로 **Hyperbolic Tangent(tanh)**가 전통적으로 많이 사용된다.

tanh는 출력을 `-1 ~ +1` 사이로 제한하므로 Hidden State의 값이 무한정 커지는 것을 어느 정도 제한할 수 있다.

하지만 tanh도 완벽한 해결책은 아니다.

tanh의 미분값 크기는 최대 `1`이고 많은 구간에서 `1`보다 작다. RNN에서는 시간축을 따라 역전파하면서 이러한 값들이 반복적으로 영향을 미치므로, Time Step이 길어질수록 Gradient가 점점 작아질 수 있다.

이를 **Vanishing Gradient**라고 한다.

---

## 4. Long-Term Dependency Problem

Gradient가 앞쪽 Time Step까지 제대로 전달되지 못하면 RNN은 오래전에 등장했던 정보가 나중의 결과에 중요하더라도 이를 학습하기 어려워진다.

이를 **Long-Term Dependency Problem(장기 의존성 문제)**이라고 한다.

```text
기본 RNN
   ↓
Time Step 증가 + BPTT
   ↓
Vanishing / Exploding Gradient
   ↓
오래된 정보 학습 어려움
   ↓
Long-Term Dependency Problem
   ↓
LSTM / GRU
```

또한 RNN 기반 Encoder-Decoder에서는 입력 Sequence의 정보를 하나의 고정 크기 **Context Vector**로 요약하여 Decoder에 전달하는 방식이 사용되었다.

긴 입력의 많은 정보를 하나의 고정 크기 Context Vector에 압축하면 정보가 충분히 보존되지 못할 수 있는데, 이를 **Bottleneck(병목) 문제**와 연결해서 이해할 수 있다.

이후 이를 개선하는 과정에서 **Attention** 개념으로 이어진다.

> Context Vector, Bottleneck, Attention은 이후 강의에서 본격적으로 학습한 뒤 추가 정리한다.

# 오늘의 핵심 정리

### DNN 학습

```text
Forward
→ Loss
→ Backpropagation
→ Gradient
→ Optimizer
→ Weight Update
```

활성화 함수는 신경망에 비선형성을 추가한다. ReLU는 심층 신경망의 Hidden Layer에서 많이 사용되며, Dropout은 학습 중 일부 출력을 랜덤하게 비활성화하여 과적합을 억제한다.

### One-Hot → Embedding

```text
One-Hot
→ 고차원 Sparse Vector
→ 차원 증가 + 의미 관계 표현의 한계
→ Embedding
→ 저차원 Dense Real-valued Vector
```

```text
Embedding(w) = One-Hot(w) × W_emb = v_w
```

Embedding Weight 역시 Loss와 Backpropagation을 통해 학습될 수 있다.

### RNN

RNN은 현재 입력 `x_t`와 이전 Hidden State `h_(t-1)`를 이용하여 새로운 Hidden State `h_t`를 만든다.

Hidden State는 이전 문자열을 그대로 저장하는 것이 아니라 **지금까지의 정보를 숫자 벡터로 요약한 상태**이다.

같은 가중치를 Time Step마다 공유하며, BPTT를 이용하여 시간축을 거슬러 학습한다.

긴 Sequence에서는 Vanishing / Exploding Gradient가 발생할 수 있으며, 특히 Vanishing Gradient는 오래된 정보를 학습하기 어렵게 만들어 **Long-Term Dependency Problem**으로 이어질 수 있다.

### [Pandas] 데이터 분석 기초

#### 1. loc & iloc

DataFrame에서 원하는 행과 열을 선택할 때 사용한다.

**`loc`**
- 행/열의 **이름(Label)**을 기준으로 선택

```python
df.loc[행라벨]
df.loc[행라벨, 컬럼명]
df.loc[시작행:종료행, [컬럼1, 컬럼2]]
df.loc[..., 시작컬럼:종료컬럼]
```

- 라벨 범위로 slicing할 경우 일반적으로 종료 라벨도 포함한다.

**`iloc`**
- 행/열의 **정수 위치(Integer Location)**를 기준으로 선택
- Python의 일반적인 slicing처럼 종료 번호는 포함하지 않는다.

```python
df.iloc[0:2, 0:2]
```

→ 행 인덱스 `0, 1` / 열 인덱스 `0, 1`

> `loc = label`, `iloc = integer location`

#### 2. 불리언 인덱싱 (Boolean Indexing)

조건을 작성하면:

```python
(df['나이'] >= 30) & (df['점수'] >= 80)
```

각 행이 조건을 만족하는지 나타내는 **Boolean Series**가 반환된다.

```text
False
True
False
...
```

즉, 아직 실제 데이터를 가져온 것이 아니라 데이터를 선택하기 위한 **Boolean Mask**이다.

실제 데이터를 필터링하려면:

```python
df[(df['나이'] >= 30) & (df['점수'] >= 80)]
```

```text
조건식
   ↓
Boolean Series
   ↓
DataFrame에 적용
   ↓
조건을 만족하는 실제 행
```

`query()`를 이용할 수도 있다.

```python
df.query('나이 >= 30 and 점수 >= 80')
```

> 조건식과 필터링 결과 모두 변수에 할당하지 않으면 별도로 저장되지 않는다.

#### 3. 결측치 처리

##### 결측치 Detection

```python
df.info()
df.isna()
df.isnull()
```

데이터에 결측치가 존재하는지 확인한다.

##### ① 결측치 삭제

```python
df.dropna()
```

결측값이 포함된 행 또는 열을 삭제한다.

##### ② 통계적 대푯값 대치 (Imputation)

결측 데이터를 삭제하지 않고 다른 대표값으로 채운다.

```python
df['column'].fillna(df['column'].mean())
df['column'].fillna(df['column'].median())
```

- 평균: `mean()`
- 중앙값: `median()`
- 결측값 채우기: `fillna()`

> 중앙값은 평균보다 이상치의 영향을 덜 받는다.

##### ③ 시계열 직전/직후 값 대치

```python
df.ffill()
df.bfill()
```

- `ffill()` → 앞의 값으로 채우기
- `bfill()` → 뒤의 값으로 채우기

##### ④ 선형 보간법 (Linear Interpolation)

```python
speed_df['속도'] = speed_df['속도'].interpolate(method='linear')
```

앞뒤 데이터의 값을 이용해 중간 값을 선형적으로 추정한다.

##### ⑤ 이상 기호 치환 및 수치형 변환

`?`, `-`, `N/A` 등 실제로는 결측치를 의미하지만 문자열로 입력된 데이터를 치환하고 필요한 자료형으로 변환한다.

##### ⑥ 결측 여부 지표 변수 생성 (Missing Indicator)

결측 여부 자체가 의미 있는 정보인 경우 새로운 변수로 생성할 수 있다.

```text
원본 값     결측 여부
20             0
NaN            1
35             0
```

#### 4. GroupBy & NumPy 변환

`groupby()`는 특정 기준으로 데이터를 그룹화하여 집계할 때 사용한다.


```text
class 기준 그룹화
```

`to_numpy()`는 Pandas의 Series/DataFrame을 NumPy 배열로 변환한다.


```text
Pandas Series / DataFrame
          ↓
      .to_numpy()
          ↓
      NumPy ndarray
```

```python
import matplotlib.pyplot as plt
```

### [Machine Learning] 머신러닝의 이해

#### 1. 머신러닝 (Machine Learning)

1. 데이터 사이언스의 한 분야
2. 데이터에 기반하여 규칙(알고리즘)을 발견하는 분야
3. 학습을 통해 찾은 규칙을 **예측과 분류** 등에 활용

```text
데이터
  ↓
학습
  ↓
규칙(Model)
  ↓
예측 / 분류
```

---

#### 2. 머신러닝의 학습 방법

##### 지도학습 (Supervised Learning)

**문제와 답이 함께 존재하는 데이터**를 이용해 학습한다.

- 문제 = **Feature(특성)**, 독립변수
- 답 = **Label(레이블)**, 종속변수

대표적인 문제 영역:

1. **Regression(회귀)** → 수치 예측
2. **Classification(분류)** → 범주 분류

```text
Feature + Label
      ↓
     학습
      ↓
새로운 Feature
      ↓
Label 예측
```

##### 비지도학습 (Unsupervised Learning)

정답(Label) 없이 Feature를 이용해 데이터 내부의 규칙이나 구조를 탐색한다.

예:

- K-means
- Clustering(군집화)

##### 준지도학습 (Semi-Supervised Learning)

Label이 있는 데이터와 없는 데이터를 함께 사용한다.

* 비지도학습으로 비슷한 데이터끼리 분류하고, 이후 정답을 확인한 데이터로 지도학습을 진행한다.(데이터 전처리 예: annotation 작업)

  > 데이터 어노테이션(Data Annotation)은 인공지능(AI)과 머신러닝 모델이 데이터를 이해할 수 있도록 이미지, 텍스트 등의 원천 데이터에 라벨(태그)이나 주석을 달아주는 필수 전처리 작업입니다.

##### 강화학습 (Reinforcement Learning)

행동의 결과로 얻는 **보상(Reward)**을 기반으로 학습한다.

#### 5. 기초 통계량

##### 평균 (Mean)

```text
데이터 전체 합 / 데이터 개수
```

##### 분산 (Variance)

데이터가 평균을 중심으로 얼마나 퍼져 있는지를 나타낸다.

```text
편차 = 데이터 값 - 평균
분산 = 편차²의 평균
```

표본을 이용해 모집단의 분산을 추정할 때는 일반적으로 `n-1`로 나눈 표본분산을 사용한다.

```text
Σ(x - x̄)² / (n - 1)
```

##### 표준편차 (Standard Deviation)

분산의 제곱근이다.

```text
표준편차 = √분산
```

데이터가 평균 주변에서 얼마나 퍼져 있는지를 원래 데이터와 같은 단위로 확인할 수 있다.

##### 피어슨 상관계수 (Pearson Correlation)

두 수치형 변수 사이의 **선형 관계의 방향과 정도**를 나타낸다.

```text
-1 ≤ r ≤ 1
```

- `r → 1` : 강한 양의 선형 관계
- `r → -1` : 강한 음의 선형 관계
- `r → 0` : 선형 관계가 약함

> 상관관계가 있다고 해서 반드시 인과관계가 있다는 의미는 아니다.

## 😊 SUMMARY

오늘은 하나의 웹페이지를 **모바일·태블릿·데스크톱 등 다양한 화면 크기에 대응시키는 반응형 웹 디자인(Responsive Web Design)**을 학습했다.

`Viewport`로 화면 영역을 설정하고, `Media Query`에서 화면 조건을 지정하여 Layout과 Style을 변경한다. 이때 Layout이 변경되는 기준점을 `Breakpoint`라고 하며, **Mobile First**에서는 모바일 CSS를 기본으로 작성한 뒤 `min-width`를 이용해 큰 화면으로 확장한다.

**Keywords:** `Viewport`, `Responsive Web Design`, `Media Query`, `Breakpoint`, `Media Type`, `Media Feature`, `Mobile First`, `Responsive Media`

# 🔄 REVIEW

## 1. Box Model — `content-box` vs `border-box`

### `content-box`

`width`, `height`가 **Content 영역의 크기**를 의미한다.

```text
실제 크기 = Content + Padding + Border
```

따라서 Padding이나 Border를 추가하면 실제 요소의 크기가 커진다.

### `border-box`

지정한 `width`, `height` 안에 **Content + Padding + Border**가 포함된다.

```text
width = Content + Padding + Border
```

> **핵심:** `content-box`는 Content 크기가 기준, `border-box`는 Border까지 포함한 전체 Box 크기가 기준이다.

---

## 2. Flex Layout — `flex-grow`와 정확한 n등분

`flex-grow`는 요소의 전체 너비가 아니라 **남은 공간(Free Space)**을 비율대로 분배한다.

따라서 모든 요소에 `flex-grow: 1`을 적용해도 기존 크기가 다르면 최종 너비가 반드시 같아지는 것은 아니다.

정확하게 같은 비율로 공간을 나누고 싶다면:

```css
.item {
    flex-basis: 0;
    flex-grow: 1;
}
```

- `flex-basis: 0` → 기본 크기의 영향을 줄임
- `flex-grow: 1` → 남은 공간을 같은 비율로 분배

# 📚 LECTURE NOTE

# 1. 반응형 웹의 시작 — Viewport

**Viewport**는 브라우저가 웹페이지를 보여주는 **화면 영역**이다.

모바일 환경에서는 `<meta name="viewport">`를 이용해 Viewport를 설정한다.

```html
<meta
    name="viewport"
    content="width=device-width, initial-scale=1.0"
>
```

### 주요 설정

| 설정 | 의미 |
|---|---|
| `width=device-width` | Viewport 너비를 Device 화면 너비에 맞춤 |
| `height=device-height` | Viewport 높이를 Device 높이에 맞춤 |
| `initial-scale` | 페이지의 초기 확대·축소 비율 |
| `minimum-scale` | 최소 배율 |
| `maximum-scale` | 최대 배율 |
| `user-scalable=yes` | 사용자 확대·축소 허용 |
| `user-scalable=no` | 사용자 확대·축소 제한 |

일반적인 반응형 웹에서는 `width=device-width, initial-scale=1.0`을 많이 사용한다.

> ⚠️ `user-scalable=no`나 `maximum-scale` 등으로 사용자의 확대를 제한하면 접근성을 저해할 수 있으므로 주의한다.

---

# 2. Responsive Web Design

**반응형 웹 디자인(Responsive Web Design)**은 하나의 웹페이지가 화면 크기와 환경에 따라 **Layout과 Style을 적절하게 변경하도록 설계하는 방식**이다.

예를 들어 화면 크기에 따라:

- Mobile → 1열
- Tablet → 2열
- Desktop → 3열

처럼 Layout을 변경할 수 있다.

이를 구현할 때 기존에 배운 **Flexbox, Grid**와 오늘 배우는 **Media Query** 등을 함께 활용한다.

> **반응형 웹 = 기기마다 별도의 페이지를 만드는 것이 아니라 하나의 페이지가 다양한 화면 크기에 대응하도록 만드는 것**

---

# 3. Media Query

**Media Query**는 화면 크기나 환경 등의 **조건에 따라 특정 CSS를 적용하는 기능**이다.

기본 구조:

```css
@media 미디어타입 and (미디어특성) {
    /* 조건을 만족할 때 적용할 CSS */
}
```

예를 들어:

```css
@media screen and (min-width: 768px) {
    body {
        font-size: 18px;
    }
}
```

→ `screen`이면서 화면 너비가 `768px 이상`일 때 해당 CSS를 적용한다.

---

# 4. Breakpoint

**Breakpoint**는 화면 크기에 따라 Layout이나 Style이 변경되는 **기준점**이다.

수업에서는 다음 범위를 기준으로 살펴봤다.

| Device | Width |
|---|---:|
| Mobile | `~ 767px` |
| Tablet | `768px ~ 1023px` |
| Desktop | `1024px ~` |

> 이 수치는 수업에서 사용하는 대표적인 기준이다. 실제 프로젝트에서는 콘텐츠와 Layout이 자연스럽게 깨지는 지점이나 디자인 요구사항에 따라 Breakpoint를 정할 수 있다.

---

# 5. Media Type & Feature

Media Query의 조건은 크게 **어떤 매체인가(Media Type)**와 **어떤 상태인가(Media Feature)**로 나누어 볼 수 있다.

## 5-1. Media Type — 적용 대상

### `screen`

컴퓨터, 태블릿, 스마트폰 등의 **화면 장치**를 대상으로 한다.

### `print`

페이지를 **인쇄할 때 적용할 CSS**를 정의한다.

```css
@media print {
    .no-print {
        display: none;
    }
}
```

### `speech`

**음성 합성 장치(Speech Synthesizer)**를 대상으로 하는 Media Type이다.

> 일반적인 스크린 리더 접근성 전체를 `@media speech`가 담당하는 것은 아니다.

### `all`

모든 Media Type을 대상으로 한다.

Media Type을 생략한 경우에도 모든 Media Type을 대상으로 조건을 검사할 수 있다.

---

## 5-2. Media Feature — 적용 조건

Media Feature는 **어떤 조건에서 CSS를 적용할지** 지정한다.

| 속성 | 의미 |
|---|---|
| `min-width` | 지정한 너비 이상 |
| `max-width` | 지정한 너비 이하 |
| `min-height` | 지정한 높이 이상 |
| `max-height` | 지정한 높이 이하 |
| `orientation` | Viewport의 가로·세로 방향 |
| `prefers-reduced-motion` | 사용자의 움직임 감소 설정 |

### `min-width` / `max-width`

- `min-width: 768px` → `768px` 이상
- `max-width: 767px` → `767px` 이하

---

### `orientation`

Viewport의 가로·세로 비율에 따라 조건을 설정한다.

- `portrait` → Viewport의 높이가 너비보다 크거나 같은 경우
- `landscape` → Viewport의 너비가 높이보다 큰 경우

```css
@media (orientation: landscape) {
    /* 가로 방향에서 적용 */
}
```

---

### `prefers-reduced-motion`

사용자가 **움직임 감소 설정**을 사용하는지 확인하여 Animation이나 Transition을 조절할 수 있다.

```css
@media (prefers-reduced-motion: reduce) {
    .animation {
        animation: none;
    }
}
```

> 실제 프로젝트에서는 모든 움직임을 일괄 제거하기보다 필요한 Animation과 Transition을 줄이거나 제거하는 방식으로 적용할 수 있다.

# 6. Mobile First

**Mobile First**는 작은 화면인 모바일을 기준으로 **기본 CSS를 먼저 작성**하고, 화면이 커질수록 Style과 Layout을 확장하는 방식이다.

```css
/* Mobile - 기본 */
.grid {
    display: grid;
    grid-template-columns: 1fr;
}

/* Tablet 이상 */
@media (min-width: 768px) {
    .grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Desktop 이상 */
@media (min-width: 1024px) {
    .grid {
        grid-template-columns: repeat(3, 1fr);
    }
}
```

흐름은 다음과 같다.

```text
Mobile 기본 CSS
        ↓ min-width
Tablet Layout 확장
        ↓ min-width
Desktop Layout 확장
```

> ⭐ **Mobile First = Mobile을 기본으로 작성 → `min-width`로 더 큰 화면에 필요한 CSS를 추가**

# 7. Responsive Media

반응형 웹에서는 Layout뿐 아니라 **이미지와 영상도 화면 크기에 맞게 처리**할 필요가 있다.

## 7-1. Style — `object-fit`

이미지나 영상이 **지정된 영역 안에 들어가는 방식**을 설정한다.

주요 값:

- `cover` → 영역을 모두 채움. 일부가 잘릴 수 있음
- `contain` → 이미지 전체를 표시. 빈 공간이 생길 수 있음

```css
img {
    width: 100%;
    height: 300px;
    object-fit: cover;
}
```

> `object-fit`은 이미지 파일의 용량이나 품질을 낮추는 속성이 아니라 **주어진 영역 안에서 이미지를 어떻게 보여줄지** 결정한다.

---

## 7-2. Responsive Image — `srcset` / `sizes`

브라우저가 화면과 이미지 표시 크기를 고려하여 **적절한 이미지 파일을 선택할 수 있도록 후보를 제공**한다.

- `srcset` → 사용할 수 있는 이미지 후보
- `sizes` → 조건에 따른 이미지의 예상 표시 크기

```html
<img
    src="image-small.jpg"
    srcset="
        image-small.jpg 480w,
        image-medium.jpg 768w,
        image-large.jpg 1200w
    "
    sizes="(max-width: 767px) 100vw, 50vw"
    alt="Responsive Image"
>
```

> 모바일 이미지 최적화는 CSS로 단순히 이미지의 "품질을 낮추는 것"이 아니라, `srcset` 등을 이용해 화면에 적절한 크기의 이미지 파일을 전달하여 불필요한 전송량을 줄이는 방식으로 이해한다.

## 🔗 오늘의 전체 흐름

```text
Viewport
→ 웹페이지가 표시될 화면 영역 설정

Responsive Web Design
→ 다양한 화면 크기에 하나의 페이지로 대응

Media Query
→ 어떤 조건에서 CSS를 변경할지 설정

Breakpoint
→ Layout이 변경될 화면 크기의 기준점 설정

Media Type
→ 어떤 매체에 적용할지 설정

Media Feature
→ 너비·높이·방향 등의 조건 설정

Mobile First
→ Mobile을 기본으로 작성하고 min-width로 확장

Responsive Media
→ 이미지와 영상도 화면에 맞게 대응
```

> ⭐ **핵심:**  
> `Viewport`로 화면을 맞추고 → `Breakpoint`를 기준으로 → `Media Query`를 적용하여 → 하나의 웹페이지가 다양한 화면 크기에 반응하도록 만든다.

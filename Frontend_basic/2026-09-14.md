## 😊 SUMMARY

웹 페이지는 **HTML로 구조를 만들고, CSS로 스타일을 지정하며, JavaScript로 동적인 기능을 구현**한다.

이번 학습에서는 HTML 문서의 기본 구조와 주요 태그를 살펴보고, **Block과 Inline 요소의 차이**, `<a>`를 이용한 페이지 이동, `<form>`과 `<input>`을 이용한 사용자 입력 구조를 학습했다.

**Keywords:** `HTML`, `Tag`, `Element`, `Attribute`, `Block`, `Inline`, `Hyperlink`, `Form`, `Input`, `Relative Path`

> 웹 페이지 구조 확인: `F12` 또는 `오른쪽 마우스 → 검사(Inspect)`

# 📚 LECTURE NOTE

# 1. 웹 문서의 기본 구조

웹 페이지는 크게 세 가지 기술로 구성된다.

| 기술 | 역할 | 확장자 |
|---|---|---|
| **HTML** | 웹 문서의 구조와 의미 | `.html`, `.htm` |
| **CSS** | 디자인과 스타일 | `.css` |
| **JavaScript** | 동적인 기능과 상호작용 | `.js` |

```text
HTML        → 뼈대
CSS         → 스타일
JavaScript  → 동작
````

## 1-1. HTML

**HTML = HyperText Markup Language**

* **HyperText** → 링크를 통해 다른 문서나 위치로 이동할 수 있는 문서
* **Markup** → 태그를 사용해 콘텐츠의 구조와 의미를 표시
* **Language** → 웹 문서를 표현하기 위한 언어

HTML의 태그(Tag)는 상품에 붙어 있는 이름표처럼 콘텐츠가 **어떤 의미와 역할을 가지는지 브라우저에게 알려준다.**

```html
<태그>내용</태그>
```

내용을 감싸지 않는 **Void Element**도 있다.

```html
<meta>
<br>
```

## 1-2. CSS

**CSS = Cascading Style Sheets**

HTML로 만든 구조에 색상, 크기, 배치 등의 스타일을 적용한다.

```html
<style>
  p {
    color: blue;
  }
</style>
```

`Cascading`은 여러 스타일 규칙이 **우선순위와 상속 등의 규칙에 따라 최종 스타일을 결정하는 방식**을 의미한다.

> 단순히 "상위 요소의 스타일이 모두 하위 요소에 전달된다"는 의미는 아니다. CSS 속성 중에는 상속되는 속성과 그렇지 않은 속성이 있다.

## 1-3. JavaScript

웹 페이지에서 사용자의 행동에 반응하거나 화면의 내용을 변경하는 등 **동적인 기능**을 담당한다.

```text
버튼 클릭
   ↓
JavaScript 실행
   ↓
화면 내용 변경
```

JavaScript는 일부 오류가 발생하더라도 브라우저나 페이지 전체가 즉시 종료되지 않는 경우가 많지만, **오류가 발생한 코드의 정상 실행까지 보장되는 것은 아니다.**

# 2. HTML 기본 구조

## 2-1. Web Standard

**웹 표준(Web Standards)**은 브라우저와 환경이 달라도 웹 콘텐츠를 일관되고 접근 가능하게 구현하기 위해 사용하는 표준 기술과 규칙이다.

이를 준수하면 브라우저별 동작 차이인 **Cross-Browser 문제**를 줄이는 데 도움이 된다.

---

## 2-2. HTML 문서 구조

```html
<!DOCTYPE html>

<html>
  <head>
    <meta charset="UTF-8">
    <title>문서 제목</title>
  </head>

  <body>
    화면에 출력되는 내용
  </body>
</html>
```

| 요소                | 역할                         |
| ----------------- | -------------------------- |
| `<!DOCTYPE html>` | 현재 문서가 HTML5 문서임을 브라우저에 알림 |
| `<html>`          | HTML 문서의 최상위 요소            |
| `<head>`          | 문서 정보와 자원 관련 설정            |
| `<body>`          | 실제 화면에 표시되는 콘텐츠            |

> `<!DOCTYPE html>`은 HTML 태그나 버전 태그라기보다 **문서 유형 선언(Doctype Declaration)**이다. 현재 웹에서는 HTML5 방식인 `<!DOCTYPE html>`을 사용한다.

# 3. HTML 태그와 요소

## 3-1. Heading

문서의 제목과 하위 제목을 표현한다.

```html
<h1>주제목</h1>
<h2>하위 제목</h2>
<h3>더 작은 제목</h3>
```

`<h1>` ~ `<h6>`는 글씨 크기를 조절하기 위한 태그가 아니라 **문서의 제목 계층 구조를 표현하는 의미적 요소**이다.

---

## 3-2. 본문 관련 요소

```html
<p>문단</p>

<b>시각적으로 굵게</b>
<strong>중요한 내용</strong>

<i>다른 어조 등의 텍스트</i>
<u>밑줄</u>

<del>삭제된 내용</del>

<br>
```

`<b>`와 `<strong>`은 기본 화면에서는 모두 굵게 보일 수 있지만 의미가 다르다.

```text
<b>       → 시각적 주의
<strong>  → 중요성 강조
```

> `<strike>`는 HTML5에서 폐기된 요소이므로 취소선 의미에는 `<del>` 등을 사용한다.

---

## 3-3. Comment

주석은 브라우저 화면에 출력되지 않으며 코드에 설명을 남기거나 일부 HTML을 임시로 출력하지 않을 때 사용할 수 있다.

```html
<!-- 설명 또는 화면에서 제외할 내용 -->
```

# 4. Block & Inline

HTML 요소는 기본 표시 방식에 따라 Block과 Inline으로 구분해 이해할 수 있다.

| 구분    | Block                                   | Inline                                    |
| ----- | --------------------------------------- | ----------------------------------------- |
| 기본 배치 | 새로운 줄에서 시작                              | 같은 줄에 이어짐                                 |
| 대표 요소 | `<div>`, `<p>`, `<h1>`~`<h6>`, `<form>` | `<span>`, `<a>`, `<strong>`, `<b>`, `<i>` |
| 주요 용도 | 문서 영역·구조                                | 문장 내부 콘텐츠                                 |

## 4-1. `<div>`

여러 요소를 하나의 영역으로 묶을 때 사용하는 대표적인 Block 요소이다.

```html
<div>
  <h2>상품 정보</h2>
  <p>상품 설명</p>
</div>
```

## 4-2. `<span>`

문장 안에서 특정 부분만 따로 묶을 때 사용하는 대표적인 Inline 요소이다.

```html
<p>
  오늘 가격은 <span>10,000원</span>입니다.
</p>
```

> Block/Inline은 기본 표시 방식에 대한 개념이며, 실제 너비·높이와 배치는 CSS의 `display` 등의 설정에 따라 변경할 수 있다.

또한 단순히 **"Inline 안에는 Block을 넣으면 안 된다"**로 외우기보다는 각 HTML 요소마다 허용되는 **Content Model**이 다르다는 점을 기억한다.

```html
<p><span>텍스트</span></p>
```

# 5. Hyperlink

## 5-1. `<a>` 태그

다른 페이지나 위치로 이동하는 **Hyperlink**를 만든다.

```html
<a href="https://example.com">이동하기</a>
```

HTML 태그에 추가적인 정보를 전달하는 값을 **Attribute(속성)**라고 한다.

```text
<a href="주소">
│   └─ Attribute
└───── Element
```

### `href`

이동할 경로를 지정한다.

**절대 경로(Absolute Path)**

```html
<a href="https://example.com/page.html">페이지</a>
```

전체 주소를 지정한다.

**상대 경로(Relative Path)**

```text
./    현재 위치
../   상위 폴더
```

```html
<a href="./about.html">현재 폴더</a>

<a href="../index.html">상위 폴더</a>
```

---

## 5-2. `target`

링크를 어디에서 열지 지정한다.

| 값         | 의미                     |
| --------- | ---------------------- |
| `_self`   | 현재 브라우징 컨텍스트에서 열기 (기본) |
| `_blank`  | 새로운 탭/창에서 열기           |
| `_parent` | 부모 브라우징 컨텍스트           |
| `_top`    | 가장 상위 브라우징 컨텍스트        |
| 이름        | 지정된 이름의 컨텍스트           |

```html
<a href="https://example.com" target="_blank">
  새 창에서 열기
</a>
```

---

## 5-3. `<iframe>`

현재 웹 페이지 내부에 다른 웹 문서를 표시할 수 있다.

```html
<iframe
  src="page.html"
  name="content">
</iframe>
```

* `src` → 출력할 문서의 경로
* `name` → iframe의 이름

# 6. Form

**Form(양식)**은 사용자가 입력한 데이터를 서버 등에 제출하기 위한 구조이다.

대표적인 예:

```text
검색창     → 검색어 제출
로그인     → ID / Password 제출
쇼핑몰     → 주문 정보 제출
```

기본 구조:

```html
<form action="/submit">
  <input type="text" name="username">
  <input type="submit" value="제출">
</form>
```

## 6-1. `<input>`

사용자로부터 데이터를 입력받는다.

| `type`     | 역할            |
| ---------- | ------------- |
| `text`     | 일반 텍스트        |
| `password` | 비밀번호          |
| `radio`    | 여러 항목 중 하나 선택 |
| `checkbox` | 여러 항목 선택 가능   |
| `submit`   | Form 제출       |
| `reset`    | Form 입력값 초기화  |
| `button`   | 일반 버튼         |

```html
<input type="text">
<input type="password">

<input type="radio" name="gender">
<input type="radio" name="gender">

<input type="checkbox" name="hobby">

<input type="submit">
```

### `name`

1. **전송할 값이 이름**

2. Form을 제출할 때 각 입력값을 식별하는 **데이터의 이름**으로 사용된다.

  - 특히 `radio`에서는 같은 `name`을 사용하면 하나의 선택 그룹으로 묶인다.

```html
<input type="radio" name="color" value="red"> Red
<input type="radio" name="color" value="blue"> Blue
```

## 6-2. `action`

Form 데이터를 제출할 **처리 URL**을 지정한다.

```html
<form action="/login">
```

실제 데이터 전송 방식은 `method` 속성으로 지정할 수 있다.

```html
<form action="/login" method="post">
```

```text
HTML → 구조
CSS → 표현
JavaScript → 동작
```

```text
Tag       → <p>, <a>, <div> 같은 문법

Block     → 영역과 문서 구조
Inline    → 문장 흐름 안의 콘텐츠
```

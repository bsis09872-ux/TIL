## Flexbox 기본

부모 요소에 `display: flex`를 적용하고 자식 요소를 배치한다.

- `flex-direction` → **주축 방향** 설정
- `justify-content` → **주축(Main Axis) 정렬**
- `align-items` → **교차축(Cross Axis) 정렬**

```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

# 1. 2장 1강 — CSS 기초와 스타일링 문법

## 1-1. Layout — Flexbox

> **Flexbox = 1차원 Layout**
>
> 하나의 주축을 기준으로 자식 요소의 **방향·정렬·크기 분배**를 제어한다.

### `flex-grow` — 남은 공간 분배

- **적용 대상:** 자식 요소(Flex Item)
- **역할:** 부모 요소에 **남아 있는 공간(Free Space)을 차지할 비율** 설정

예를 들어 두 요소에 각각 `1`, `3`을 지정하면 남은 공간을 `1 : 3`으로 나눈다.

```css
.item1 { flex-grow: 1; }
.item2 { flex-grow: 3; }
```

- `item1` → 남은 공간의 `1/4`
- `item2` → 남은 공간의 `3/4`

> ⭐ `flex-grow`는 **요소 전체 크기의 비율이 아니라 남은 공간의 분배 비율**이다.

정확하게 동일한 비율로 공간을 나누고 싶다면 기본 크기의 영향을 없애고 분배할 수 있다.

```css
.item {
    flex-basis: 0;
    flex-grow: 1;
}
```

---

### `flex-shrink` — 공간 부족 시 축소

- **적용 대상:** 자식 요소(Flex Item)
- **역할:** 부모 공간이 부족할 때 **자식 요소가 줄어드는 비율**
- 값은 축소 비율의 가중치
- `0` → 축소하지 않음

> 실제 축소되는 크기는 `flex-shrink` 값뿐 아니라 요소의 기본 크기 등에도 영향을 받는다.

---

### `flex-basis` — 기본 크기

- Flex Item의 **기본 크기**
- 기본값: `auto`
- `flex-grow`, `flex-shrink`가 공간을 계산할 때 기준이 됨

---

### `flex-wrap` — 줄바꿈

부모 공간이 부족할 때 자식 요소의 줄바꿈 여부를 설정한다.

- `nowrap` → 줄바꿈 X, 기본값
- `wrap` → 공간이 부족하면 다음 줄로 배치

---

## 1-2. Layout — CSS Grid

> **Grid = 2차원 격자 Layout**
>
> 행(Row)과 열(Column)을 함께 사용하여 요소를 배치한다.

### Grid 구조 설정

- `grid-template-columns` → 열(Column) 구성
- `grid-template-rows` → 행(Row) 구성
- `fr` → 남은 공간에 대한 비율
- `repeat(개수, 크기)` → 같은 크기의 행·열 반복

사용 예:

```css
.container {
    display: grid;
    grid-template-columns: 150px 1fr 2fr;
}
```

→ 첫 번째 열은 `150px`, 남은 공간은 `1 : 2`로 분배

같은 크기의 열을 반복할 때:

```css
grid-template-columns: repeat(3, 1fr);
```

→ 같은 비율의 열 3개

---

### Grid 간격 — `gap`

Grid Item 사이의 간격을 설정한다.

- `row-gap` → 행 사이 간격
- `column-gap` → 열 사이 간격
- `gap` → 행·열 간격 단축 속성

`gap` 값이 하나면 행과 열에 동일하게 적용된다.

`gap: 20px 10px`처럼 두 개를 사용하면 **행 → 열** 순서로 적용된다.

---

### Grid 영역 — `grid-column` / `grid-row`

Grid Item이 몇 칸을 차지할지 설정한다.

```css
.item {
    grid-column: 1 / 3;
}
```

→ Grid Line `1`부터 `3`까지이므로 **열 2칸 차지**

`span`을 이용할 수도 있다.

- `grid-column: span 2` → 열 2칸 차지
- `grid-row: span 2` → 행 2칸 차지

> `1 / 3`의 숫자는 열 자체의 번호가 아니라 **Grid Line 번호**이다.

---

### Grid 정렬 — `place-items`

Grid Item을 **각 Grid 영역 안에서 정렬**한다.

주요 값: `stretch`(기본값), `start`, `end`, `center`

`place-items`는 다음 두 속성을 합친 단축 속성이다.

```text
place-items
├─ align-items
└─ justify-items
```

값을 하나만 사용하면 두 속성에 같은 값이 적용된다.

```css
place-items: center;
```

→ `align-items: center` + `justify-items: center`

값을 두 개 사용하면:

```css
place-items: center start;
```

→ `align-items: center` + `justify-items: start`

> **Flex:** `justify-content` + `align-items`로 주축·교차축 정렬  
> **Grid:** `place-items`로 각 Grid 영역 내부의 두 축 Item 정렬 가능

## 1-3. Style — Text & Font

> 글자의 **색상·크기·간격·정렬·두께·글꼴** 등을 설정한다.

### 색상과 크기

- `color` → 글자 색상
  - 색상명, HEX Code, `rgb()` 등
- `font-size` → 글자 크기
  - 절대 단위: `px`, `pt`
  - 상대 단위: `em`, `rem`

`em`은 해당 요소의 `font-size` 계산에 사용되는 상대 단위이고, `rem`은 Root 요소인 `<html>`의 `font-size`를 기준으로 한다.

---

### 글자 및 줄 간격

- `line-height` → 한 줄이 차지하는 높이
- `letter-spacing` → 글자 사이 간격
- `word-spacing` → 단어 사이 간격

`line-height`는 단위 없는 비율, `%`, `px`, `em`, `rem` 등을 사용할 수 있다.

```css
p {
    font-size: 20px;
    line-height: 1.5;
}
```

→ 한 줄이 차지하는 높이는 `30px`

---

### 줄바꿈 — `word-break`

단어가 영역을 넘어갈 때 **어디에서 줄을 바꿀지** 설정한다.

주요 값:

- `normal` → 기본 줄바꿈 규칙
- `break-all` → 글자 단위로 줄바꿈 가능
- `keep-all` → 한중일(CJK) 텍스트에서 단어 중간 줄바꿈 억제

> `wrap`, `nowrap`은 `word-break`의 속성값이 아니다. 줄바꿈 자체를 막을 때는 `white-space: nowrap` 등을 사용한다.

---

### 글자 두께 — `font-weight`

- `normal` → 일반적으로 `400`
- `bold` → 일반적으로 `700`
- 숫자 → `100` ~ `900` 등

> 실제 지원하는 두께는 사용하는 Font에 따라 다르다.

---

### 글 정렬 — `text-align`

Block Container 내부의 **Inline Content를 정렬**한다.

- `left` → 왼쪽
- `right` → 오른쪽
- `center` → 가운데
- `justify` → 양쪽 정렬

---

### 글자 모양

**`font-style`**

- `normal` → 기본
- `italic` → Italic 기울임체
- `oblique` → 기울여 표현

**`text-decoration`**

- `underline` → 밑줄
- `line-through` → 취소선
- `none` → 없음

---

### 글꼴 — `font-family`

여러 글꼴을 지정하면 앞의 글꼴을 사용할 수 없을 때 순서대로 다음 글꼴을 사용한다.

```css
font-family: "Malgun Gothic", "Apple Gothic", sans-serif;
```

- 폰트명에 공백이 있으면 따옴표로 감싸기
- `sans-serif`와 같은 Generic Family는 일반적으로 따옴표 없이 사용

---

## 1-4. Style — Overflow

> 요소의 크기보다 **콘텐츠가 넘쳤을 때 처리 방법**을 설정한다.

- `visible` → 넘친 콘텐츠도 표시, 기본값
- `hidden` → 넘친 부분 숨김
- `scroll` → 스크롤 가능
- `auto` → 필요한 경우 스크롤 가능
- `overflow-x` → 가로축 처리
- `overflow-y` → 세로축 처리

---

## 1-5. Box Style — Border

> Box Model의 **경계선(Border)**을 꾸미는 속성

- `border-width` → 두께
- `border-style` → 선의 모양
  - `none`, `solid`, `dashed`, `dotted`, `double`
- `border-color` → 색상
- `border-radius` → 모서리 둥글게

여러 Border 속성은 한 번에 작성할 수 있다.

```css
.box {
    border: 2px solid red;
    border-radius: 10px;
}
```

방향별로 `border-top`, `border-bottom`, `border-left`, `border-right`도 사용할 수 있다.

> `border`는 **Box Model의 구성 요소**이면서, 위 속성들을 이용해 시각적 Style도 설정한다.

---

## 1-6. Style — Background

> 요소의 **배경색과 배경 이미지**를 설정한다.

### 기본 속성

- `background-color` → 배경색
- `background-image` → `url("이미지 경로")`

### 이미지 반복 — `background-repeat`

- `repeat` → X·Y축 모두 반복, 기본값
- `repeat-x` → X축 반복
- `repeat-y` → Y축 반복
- `no-repeat` → 반복하지 않음

### 이미지 위치 — `background-position`

```css
background-position: 100px 50px;
```

- 첫 번째 값 → X축: 왼쪽에서 오른쪽으로 `100px`
- 두 번째 값 → Y축: 위에서 아래로 `50px`

`left top`, `center center` 등의 위치 Keyword도 사용할 수 있다.

### 이미지 크기 — `background-size`

- 직접 크기 지정: `200px 100px`
- `cover` → 영역을 모두 채움. 이미지 일부가 잘릴 수 있음
- `contain` → 이미지 전체가 보이도록 맞춤. 빈 공간이 생길 수 있음

### 스크롤 — `background-attachment`

- `scroll` → 기본값
- `fixed` → 배경을 Viewport 기준으로 고정
- `local` → 요소 내부의 스크롤 콘텐츠와 함께 배경도 스크롤

### 단축 표기

여러 Background 속성을 한 번에 작성할 수 있다.

```css
background: white url("image.png") no-repeat center / cover;
```

> `background-size`를 단축 표기할 때는 `position / size` 형태로 작성한다.

# 2. 2장 2강 — CSS Positioning

> **Positioning = 요소를 어디를 기준으로 배치할지 설정**

`position`은 요소의 위치를 결정하는 **배치 기준**을 설정한다.

## 2-1. `static`

- 기본값
- 일반적인 문서 흐름에 따라 배치

```text
static = 별도의 위치 기준을 지정하지 않은 기본 배치
```

---

## 2-2. `relative`

- 요소의 **원래 위치를 기준**으로 이동
- 원래 차지하던 공간은 유지
- `absolute` 자식의 배치 기준을 만들 때도 자주 사용

---

## 2-3. `absolute`

- 일반적인 문서 흐름에서 벗어나 배치
- 가장 가까운 **`static`이 아닌 조상 요소**를 기준으로 위치 결정

대표적인 사용:

```css
.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 0;
    right: 0;
}
```

→ `.child`는 `.parent`를 기준으로 오른쪽 위에 배치

> `absolute`가 항상 문서 전체를 기준으로 하는 것은 아니다.

---

## 2-4. `fixed`

- 일반적으로 **Viewport를 기준으로 위치 고정**
- 스크롤해도 같은 화면 위치에 유지

> **Viewport:** 현재 브라우저에서 웹페이지가 보이는 화면 영역

---

## 2-5. 위치 지정 속성

`position`과 함께 다음 속성으로 위치를 조절한다.

- `top` → 위쪽 기준
- `right` → 오른쪽 기준
- `bottom` → 아래쪽 기준
- `left` → 왼쪽 기준

### Position 한눈에 보기

| 값 | 기준 | 특징 |
|---|---|---|
| `static` | 일반 문서 흐름 | 기본값 |
| `relative` | 자신의 원래 위치 | 기존 공간 유지 |
| `absolute` | 가까운 Positioned 조상 | 일반 흐름에서 벗어남 |
| `fixed` | Viewport | 화면에 고정 |

---

## 2-6. `z-index`

요소가 겹칠 때 **쌓이는 순서(Stacking Order)**를 조절한다.

```css
.popup {
    position: fixed;
    z-index: 100;
}
```

> `z-index`는 단순히 숫자가 크면 페이지의 모든 요소보다 무조건 위에 올라오는 개념은 아니다. **Stacking Context**의 영향을 받는다.

---

## 🧩 CSS 속성 역할 한눈에 보기

| 분류 | 주요 속성 | 역할 |
|---|---|---|
| **Layout — Flex** | `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-grow`, `flex-shrink`, `flex-basis`, `flex-wrap` | 1차원 요소 배치·정렬·크기 분배 |
| **Layout — Grid** | `display: grid`, `grid-template-*`, `gap`, `grid-column`, `grid-row`, `place-items` | 2차원 행·열 배치 및 정렬 |
| **Text Style** | `color`, `font-*`, `line-height`, `letter-spacing`, `word-spacing`, `text-*` | 글자 모양과 정렬 |
| **Overflow** | `overflow`, `overflow-x`, `overflow-y` | 넘치는 콘텐츠 처리 |
| **Box Style** | `border`, `border-radius` | Box의 경계선 및 모양 |
| **Background Style** | `background-*` | 배경색·이미지 표현 |
| **Positioning** | `position`, `top`, `right`, `bottom`, `left`, `z-index` | 요소의 배치 기준·위치·쌓임 순서 |

> ⭐ **큰 틀로 구분하기**
>
> **Flex / Grid** → 요소들을 **어떻게 정렬하고 배치할까?**  
> **Font / Border / Background** → 요소를 **어떻게 꾸밀까?**  
> **Position** → 요소를 **어디를 기준으로 놓을까?**

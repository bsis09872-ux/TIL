## 강의  노트
#### 플렉스 (이어서)
##### flex-grow
1. 자식 요소 적용
2. 남아 있는 공백을 차지할 비율 설정
    - 남은 공백을 나눠주는 것! 2개가 있으면 2:1로 나눠주고, 1개가 있으면 1:1로 줌. 3개면 3:1로 나눠줌.
    - 만약 첫 요소에 1을, 두번째 요소에 3을 배정하면 각각 1/4과 3/4를 배정 받는다.
    - **남아있는 공백에 대한 분배** 이기 때문에 요소의 크기와는 상관이 없다.
    - 정확한 비율로 공간을 나눠주고 싶을때는 요소의 너비를 없애고, flex-grow로 균등 분배하여 배치한다. ⭐
##### flex-shrink
1. 부모 요소의 공간이 부족할때, 자식 요소의 크기를 줄이는 비율.
2. 비율 가중치
3. 0 : 요소를 축소 x
4. flex-basis : 요소의 기본사이즈 (auto - 기본값)

##### flex-wrap
1. wrap: 부모 요소의 너비가 부족하면 다음칸에 개행
2. nowrap (기본값) - 개행 x

#### 2장 1강 CSS 기초와 스타일링 문법
##### Font
1. color 글 색상 (색상명, hexcode, rgb)
2. font-size 글 크기 (절대크기와 . 상대크기em,rem)
3. line-height 행간 (기본값: 1,2)
    - 1은 글의 높이, 2는 여백율(20%) 상단10% 하단 10% 할당.
    - 비율(권장사항), %, px,em,rem

4. letter-spacing 자간
5. word-spacing 단어 사이 간격
6. word-break : wrap/nowrap/break-all

7. font-weight 폰트의 두께
    - normal(기본값) -> 400
    - bold 두껍게 -> 700
    - 숫자로 설정도 가능 (가늘게100~900두껍게)
        - 폰트별로 지원하는 두께는 다르다 (확인 필요)

8. text-align
    - 인라인 요소(글)에 대한 정렬
        - 글이 있는 블록 요소 내에서 정렬
        - 글 정렬은 글이 담긴 요소에서 가능

    - left (기본값) - 왼쪽 정렬
    - right - 오른쪽 정렬
    - center - 중앙 정렬
    - justify 양쪽 정렬 (전체 문장 기능 통일!)

9. font-style
    - normal (기본값)
    - italic 기울임체
    - oblique 흘림체 (기울임체 각도 조절 가능 `oblique 90deg;  `)

10. text-decoration
    - underline 밑줄
    - line-through 취소선
    - none (기본값)

11. font-family : 글꼴
    - `font-family: 폰트명, 대체폰트1, 대체폰트2, ....`
    - 현재 시스템에서 원래 폰트를 못읽어 오면 순서대로 그 다음 폰트를 사용하도록 함.
    - 폰트명에 공백이 있으면 따옴표로 감싸기!

    - ex: 
    `font-family: 'Malgun Gothic', 'Apple Gothic', 'Sans-serif'`

##### 보충 개념들
- overflow(x,y)
    - visible 넘치는 컨텐츠가 있어도 보이기 (기본값)

    - auto 스크롤바 노출시켜, 넘치는 콘텐츠에 대해서 없으면 미노
    - overflow-x
    - overflow-y

---
- border 경계선
    1. border-width: 두께
    2. border-style: none (기본값)/ solid (직선)/ dashed (파선)/ dotted (점선)/ double(이중실선)
    3. border-color: 색상
        - 단축 표현법
        `border: 두께 스타일 색상;`
            - 예: `border 2px solid red;`
        - top, bottom, left, right (예. `border-top:...`)
    4. border-radius 모서리 둥글게 (반지름)

---
- background 배경
    1. background-color : 배경색
    2. background-image : url("이미지 경로")
    3. background-repeat: 
        - repeat(기본값) : x,y축 모두 반복
        - repeat-x : x축 반복
        - repeat-y : y축 반복
        - no-repeat : 하나만 출력
    4.  background-position: 배경이미지 위치설정
        - 예: `background-position: 100px 50px;`
        &rarr; **좌에서 우로** 100픽셀만큼 내려온다. **위에서 아래로** 50픽셀만큼 이동한다.
            - 위치로도 배치 가능:
            - 예: `background-position: left top;` / 
        `background-position: center center;`
    5. background-size: 바탕 크기
        - 예: `background-size: 200px 100px;` &rarr; 가로 200 x 세로 100
        - cover &rarr; 영역을 모두 채운다. (이미지의 비율이 배경 요소와 차이가 있는 경우 일부를 자른다.)
        - contain &rarr; (이미지가 모두 보일 수 있도록 채운다.)
    6. background-attachment
        - fixed : 스크롤시 배경은 고정. 따라서 내려오지 않음.
        - scroll : 스크롤시 배경 이미지도 함께 스크롤
        - local : ?

    7. **단축 표기법**
    - background: 색상* 이미지* 반복 고정 위치 사이즈**
        * 둘 중 한가지는 정의해야함!*
        * 그 뒤 나머지는 선택사항**

##### positioning (2장 2강)
- position: 위치 (배치)
    - 절대위치 &rarr; static (기본값) 
    - 상대위치 &rarr; (배치 기준 별로...)
        - relative 속성이 정의 되어 있는 요소
        - absolute 문서 전체가 기준
        - fixed 뷰포트 기준
            > 뷰포트 (viewport): 현재 보이는 화면

            - 속성: left(좌에서 우), right(우에서 좌), top(위에서 아래), bottom(아래서 위로)
        - 층위 설정 가능 z-index

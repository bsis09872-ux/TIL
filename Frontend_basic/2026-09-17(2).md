### Flexbox

# 📚 LECTURE NOTE

## 1. Flexbox

### 1-1. `flex-grow`

**자식 요소(Flex Item)**에 적용하며 부모 영역에서 **남아 있는 공간을 어떤 비율로 나누어 가질지** 설정한다.

```css
.item1 {
    flex-grow: 1;
}

.item2 {
    flex-grow: 3;
}
```

남은 공간을 기준으로:

```text
item1 → 1 / 4
item2 → 3 / 4
```

즉, `flex-grow`는 **남아 있는 공백에 대한 분배 비율**이다.

> 요소의 최종 크기를 단순히 `1:3`으로 만든다는 의미가 아니라, **기본 크기를 제외하고 남은 공간을 1:3으로 분배**한다.

정확한 비율로 공간을 나누고 싶다면 기본 너비의 영향을 없앤 뒤 `flex-grow`를 이용해 균등하게 배치할 수 있다.

---

### 1-2. `flex-shrink`

부모 요소의 공간이 부족할 때 **자식 요소를 얼마나 줄일지에 대한 축소 비율**을 설정한다.

```css
.item {
    flex-shrink: 1;
}
```

- 값이 클수록 축소에 더 적극적으로 참여
- `0` → 해당 요소를 축소하지 않음

> 실제 축소량은 `flex-shrink` 값뿐 아니라 요소의 기본 크기 등도 함께 영향을 준다.

---

### 1-3. `flex-basis`

Flex Item의 **기본 크기**를 설정한다.

```css
.item {
    flex-basis: auto;
}
```

- `auto` → 기본값
- `flex-grow`, `flex-shrink`가 계산되기 전 기준 크기로 사용

---

### 1-4. `flex-wrap`

부모 공간이 부족할 때 Flex Item을 다음 줄로 넘길지 설정한다.

```css
.container {
    flex-wrap: wrap;
}
```

| 값 | 의미 |
|---|---|
| `nowrap` | 줄바꿈 X (기본값) |
| `wrap` | 공간이 부족하면 다음 줄로 배치 |

## 2. CSS Grid

**CSS Grid**는 행(Row)과 열(Column)을 이용하는 **2차원 격자 Layout**이다.

```css
.container {
    display: grid;
}
```

```text
Flexbox → 1차원 중심 Layout
Grid    → 행 + 열의 2차원 Layout
```

---

### 2-1. `grid-template-columns` / `grid-template-rows`

Grid의 열과 행 크기를 설정한다.

```css
.container {
    grid-template-columns: 150px 150px 300px;
}
```

→ 3개의 Column 생성

행은 다음과 같이 설정한다.

```css
grid-template-rows: 100px 200px;
```

---

### `fr`

남은 공간을 비율로 분배하는 Grid 단위이다.

```css
grid-template-columns: 150px 1fr 2fr;
```

```text
150px → 고정
나머지 공간 → 1 : 2 비율로 분배
```

---

### `repeat()`

반복되는 Grid 크기를 간단하게 작성한다.

```css
grid-template-columns: repeat(3, 1fr);
```

→ 같은 크기의 Column 3개 생성

---

### 2-2. `gap`

Grid Item 사이의 간격을 설정한다.

```css
row-gap: 20px;
column-gap: 10px;
```

단축 표현:

```css
gap: 20px 10px;
```

```text
20px → 행 간격
10px → 열 간격
```

모든 간격을 동일하게:

```css
gap: 30px;
```

---

### 2-3. `grid-column`

Grid Item이 차지할 열을 지정한다.

```css
grid-column: 1 / 3;
```

→ Grid Line `1`부터 `3`까지, 즉 **2칸을 차지**

```css
grid-column: span 2;
```

→ 현재 위치에서 **열 2칸 차지**

> `1 / 3`의 숫자는 단순히 "1번 열~3번 열"이 아니라 **Grid Line 번호**를 의미한다.

---

### 2-4. `grid-row`

행을 기준으로 동일하게 적용한다.

```css
grid-row: 1 / 3;
```

→ 2개의 행 차지

```css
grid-row: span 2;
```

→ 행 2칸 차지

---

### 2-5. `place-items`

Grid Item을 각 Grid 영역 안에서 정렬한다.

```css
place-items: center;
```

- `stretch` → 기본값
- `start`
- `end`
- `center`

## 3. Font & Text

### 3-1. `color`

글자 색상을 지정한다.

```css
color: red;
color: #ff0000;
color: rgb(255, 0, 0);
```

---

### 3-2. `font-size`

글자 크기를 지정한다.

- `px`, `pt` → 절대적인 크기 표현에 주로 사용
- `em`, `rem` → 상대 크기

```text
em  → 현재 요소의 font-size를 기준으로 계산
rem → Root(<html>)의 font-size 기준
```

---

### 3-3. `line-height`

줄 높이, 즉 **한 줄이 차지하는 높이**를 설정한다.

```css
line-height: 1;
line-height: 1.5;
line-height: 20px;
line-height: 150%;
```

단위 없는 숫자를 사용하면 현재 글자 크기에 대한 비율로 계산된다.

```text
font-size: 20px
line-height: 1.5

→ 한 줄 높이 30px
```

> 필기의 `기본값 1,2`는 정확히는 브라우저의 기본 `line-height`가 폰트 등에 따라 결정되므로 고정된 `1.2`라고 볼 수는 없다.

---

### 3-4. 글자 간격

```css
letter-spacing: 2px;
word-spacing: 5px;
```

- `letter-spacing` → 글자 사이 간격
- `word-spacing` → 단어 사이 간격

---

### 3-5. `word-break`

텍스트가 영역을 넘어갈 때 **단어를 어디에서 줄바꿈할지** 제어한다.

```css
word-break: normal;
word-break: break-all;
word-break: keep-all;
```

> ⚠️ 필기의 `wrap / nowrap`은 `word-break`의 값이 아니다. 줄바꿈 여부를 제어할 때는 `white-space: nowrap` 등이 사용된다.

---

### 3-6. `font-weight`

글자의 두께를 설정한다.

```css
font-weight: normal; /* 보통 400 */
font-weight: bold;   /* 보통 700 */

font-weight: 100;
font-weight: 400;
font-weight: 700;
font-weight: 900;
```

> 실제 사용할 수 있는 두께는 Font가 지원하는 Weight에 따라 다르다.

---

### 3-7. `text-align`

Block Container 내부의 Inline Content를 정렬한다.

```css
text-align: left;
text-align: right;
text-align: center;
text-align: justify;
```

- `left` → 왼쪽
- `right` → 오른쪽
- `center` → 가운데
- `justify` → 양쪽 정렬

---

### 3-8. `font-style`

```css
font-style: normal;
font-style: italic;
font-style: oblique;
```

- `normal` → 기본
- `italic` → 폰트가 제공하는 Italic 스타일
- `oblique` → 글자를 기울여 표현

일부 환경에서는 다음과 같이 각도를 지정할 수도 있다.

```css
font-style: oblique 20deg;
```

---

### 3-9. `text-decoration`

```css
text-decoration: underline;
text-decoration: line-through;
text-decoration: none;
```

---

### 3-10. `font-family`

사용할 글꼴과 대체 글꼴을 순서대로 설정한다.

```css
font-family: "Malgun Gothic", "Apple Gothic", sans-serif;
```

앞의 Font를 사용할 수 없으면 다음 Font를 순서대로 사용한다.

> 폰트 이름에 공백이 있으면 따옴표로 감싼다. `sans-serif`처럼 Generic Family는 일반적으로 따옴표 없이 사용한다.

## 4. Overflow

요소의 영역보다 콘텐츠가 커졌을 때 처리 방법을 지정한다.

```css
overflow: visible;
overflow: hidden;
overflow: scroll;
overflow: auto;
```

| 값 | 의미 |
|---|---|
| `visible` | 넘친 콘텐츠 표시 (기본값) |
| `hidden` | 넘친 부분 숨김 |
| `scroll` | 스크롤 가능한 영역 생성 |
| `auto` | 필요한 경우 스크롤 가능 |

축별로 설정할 수도 있다.

```css
overflow-x: auto;
overflow-y: hidden;
```

## 5. Border

요소의 경계선을 설정한다.

```css
border-width: 2px;
border-style: solid;
border-color: red;
```

### `border-style`

```text
none    → 없음
solid   → 실선
dashed  → 파선
dotted  → 점선
double  → 이중 실선
```

### 단축 표현

```css
border: 2px solid red;
```

> ⚠️ 필기의 `border 2px solid red;`에서 `:`가 빠져 있어 수정.

방향별 설정도 가능하다.

```css
border-top: 1px solid black;
border-bottom: 1px solid black;
```

### `border-radius`

모서리를 둥글게 만든다.

```css
border-radius: 10px;
```

## 6. Background

### 6-1. 기본 속성

```css
background-color: #fff;
background-image: url("image.png");
```

---

### 6-2. `background-repeat`

```css
background-repeat: repeat;
background-repeat: repeat-x;
background-repeat: repeat-y;
background-repeat: no-repeat;
```

- `repeat` → X/Y축 반복 (기본값)
- `repeat-x` → X축 반복
- `repeat-y` → Y축 반복
- `no-repeat` → 반복 X

---

### 6-3. `background-position`

배경 이미지의 위치를 설정한다.

```css
background-position: 100px 50px;
```

```text
100px → 가로(X), 왼쪽에서 오른쪽
50px  → 세로(Y), 위에서 아래
```

> ⚠️ `100px만큼 내려온다`가 아니라 **오른쪽으로 100px**, 그다음 **아래로 50px**이다.

키워드도 사용할 수 있다.

```css
background-position: left top;
background-position: center center;
```

---

### 6-4. `background-size`

```css
background-size: 200px 100px;
```

→ 가로 `200px`, 세로 `100px`

```css
background-size: cover;
background-size: contain;
```

- `cover` → 영역 전체를 채움. 비율 차이에 따라 이미지 일부가 잘릴 수 있음
- `contain` → 이미지 전체가 보이도록 맞춤. 남는 공간이 생길 수 있음

---

### 6-5. `background-attachment`

```css
background-attachment: fixed;
background-attachment: scroll;
background-attachment: local;
```

- `fixed` → Viewport를 기준으로 배경 고정
- `scroll` → 요소와 함께 배경도 스크롤되는 기본 방식
- `local` → 요소 내부의 스크롤되는 콘텐츠와 함께 배경도 스크롤

---

### 6-6. 단축 표기

여러 Background 속성을 한 번에 지정할 수 있다.

```css
background: color image repeat attachment position / size;
```

예:

```css
background: #fff url("image.png") no-repeat center / cover;
```

> 필요한 속성만 조합할 수 있으며, `background-size`를 함께 단축 표기할 때는 일반적으로 `position / size` 형태로 작성한다.

## 7. Positioning

`position`은 요소의 **배치 방식과 위치의 기준**을 설정한다.

### 7-1. `static`

```css
position: static;
```

기본값으로, 일반적인 문서 흐름에 따라 배치된다.

> ⚠️ `static = 절대위치`가 아니라 **기본 배치 방식**이다.

---

### 7-2. `relative`

```css
position: relative;
```

요소의 **원래 배치 위치를 기준**으로 이동한다.

```css
position: relative;
top: 20px;
left: 10px;
```

또한 `absolute` 자식 요소의 **위치 기준을 만들어 줄 때** 자주 사용한다.

---

### 7-3. `absolute`

```css
position: absolute;
```

일반적으로 가장 가까운 **`static`이 아닌 조상 요소**를 기준으로 배치한다.

```html
<div class="parent">
    <div class="child"></div>
</div>
```

```css
.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 0;
    left: 0;
}
```

> ⚠️ `absolute = 항상 문서 전체 기준`은 아니다. 위치가 지정된 조상이 없다면 초기 Containing Block 등을 기준으로 배치된다.

---

### 7-4. `fixed`

```css
position: fixed;
```

일반적으로 **Viewport**를 기준으로 위치가 고정된다.

> **Viewport** → 현재 브라우저에서 보이는 화면 영역

위치는 다음 속성으로 조절한다.

```css
top: 0;
right: 0;
bottom: 0;
left: 0;
```

---

### Position 비교

| 값 | 주요 배치 기준 | 특징 |
|---|---|---|
| `static` | 일반 문서 흐름 | 기본값 |
| `relative` | 자신의 원래 위치 | 원래 자리 기준 이동 |
| `absolute` | 가장 가까운 positioned 조상 | 일반 흐름에서 벗어나 배치 |
| `fixed` | 일반적으로 Viewport | 화면에 고정 |

### `z-index`

요소가 겹쳤을 때 **쌓이는 순서(Stacking Order)**를 조절하는 데 사용한다.

```css
z-index: 10;
```

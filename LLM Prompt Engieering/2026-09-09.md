## 😊 SUMMARY

이번 학습에서는 LLM을 활용한 애플리케이션을 만들기 위한 **LangChain Framework**의 기본 구조를 학습했다. LangChain이 여러 LLM과 도구를 공통적인 방식으로 사용할 수 있도록 **추상화(Abstraction)**한다는 개념을 이해하고, 변수를 이용해 재사용 가능한 **Prompt Template**을 만드는 방법을 살펴봤다.

마지막으로 **LCEL(LangChain Expression Language)**을 이용해 `Prompt → Model → Parser`를 하나의 **Chain**으로 연결하고, 각 단계의 출력이 다음 단계의 입력으로 전달되는 AI 애플리케이션의 기본 데이터 흐름을 학습했다.

# 📚 LECTURE NOTE

# 1. LangChain Framework

**LangChain**은 LLM을 활용한 애플리케이션을 개발할 때 Prompt, Model, Parser 등의 구성 요소를 연결하여 사용할 수 있도록 도와주는 **Framework**다.

```text
사용자 입력
    ↓
Prompt
    ↓
LLM
    ↓
Output
```

LangChain을 사용하면 이러한 구성 요소를 하나의 흐름으로 연결할 수 있다.

```text
Prompt
  │
  ▼
Model
  │
  ▼
Parser
  │
  ▼
Result
```

# 2. Abstraction - 추상화

수업에서 말한 **"프레임워크가 추상화가 잘 되어 있다"**는 것은 특정 LLM이나 특정 Tool에만 국한되지 않고 여러 구성 요소를 **공통적인 방식으로 다룰 수 있도록 만들어져 있다**는 의미로 이해할 수 있다.

```text
OpenAI ─────┐
            │
다른 LLM ───┼── 공통적인 방식
            │
Tools ──────┘
```

즉, 각각의 서비스가 내부적으로 어떻게 구현되어 있는지를 모두 직접 다루기보다 **공통적으로 필요한 기능을 일정한 인터페이스로 사용할 수 있도록 만든 것**이다.

> **Abstraction(추상화)** = 서로 다른 구현에서 공통적인 부분을 뽑아 사용자가 보다 단순하고 일관된 방식으로 다룰 수 있도록 하는 것

### Framework와 추상화

```text
각기 다른 구현
OpenAI / 다른 LLM / Tools
          ↓
     Abstraction
          ↓
공통적인 사용 방식 제공
          ↓
      Framework
```

따라서 LangChain에서는 모델이나 도구가 달라져도 비슷한 구조로 AI 애플리케이션을 구성할 수 있다.

# 3. Prompt Template

## 3-1. Template

**Template**은 반복적으로 사용하는 구조에서 일부 값만 바꿔 사용할 수 있도록 만든 틀이다.

Prompt에서도 마찬가지로 **치환할 변수가 포함된 Prompt의 틀**을 만들 수 있다.

```text
"{topic}에 대해 설명해주세요."
```

여기서:

```text
{topic}
```

은 실제 값이 들어갈 **변수(Variable)** 다.

예를 들어:

```text
topic = "Transaction"
```

을 전달하면:

```text
Transaction에 대해 설명해주세요.
```

라는 실제 Prompt를 만들 수 있다.

```text
Prompt Template
      +
   Variable
      ↓
실제 Prompt
```

---

## 3-2. ChatPromptTemplate

LangChain에서는 `ChatPromptTemplate`을 이용해 Chat Model에 전달할 Prompt Template을 구성할 수 있다.

개념적인 흐름은 다음과 같다.

```text
입력 Dictionary
      ↓
Prompt Template
      ↓
변수 치환
      ↓
완성된 Prompt
      ↓
Chat Model
```

예를 들어 Template에:

```text
{topic}
```

이라는 변수가 있다면 입력 Dictionary에서 해당 값을 전달한다.

```text
{"topic": "SQL"}
        ↓
Prompt Template
        ↓
"SQL에 대해 설명해주세요."
```

> **Prompt Template = 매번 Prompt 전체를 새로 작성하는 대신 변수만 바꿔 재사용할 수 있는 Prompt의 틀**

# 4. LCEL

**LCEL(LangChain Expression Language)**은 LangChain의 여러 구성 요소를 연결해 하나의 **Chain**을 구성하는 표현 방식이다.

수업에서 사용한 기본 구조:

```python
chain = prompt_template | model | parser
```

여기서 `|`를 이용해 각 구성 요소를 순서대로 연결한다.

```text
prompt_template
       |
       ▼
     model
       |
       ▼
     parser
```

앞 단계의 **Output이 다음 단계의 Input으로 전달**된다.

---

# 5. Chain과 데이터 흐름

오늘 실습의 핵심적인 데이터 흐름은 다음과 같다.

```text
입력 Dictionary
      ↓
ChatPromptTemplate
      ↓
ChatOpenAI
      ↓
StrOutputParser
      ↓
최종 문자열
```

## 5-1. Prompt Template

```text
Input
  ↓
Prompt Template
```

입력받은 데이터를 이용해 LLM에 전달할 Prompt를 구성한다.

---

## 5-2. Model

```text
완성된 Prompt
      ↓
ChatOpenAI
      ↓
LLM 응답
```

Prompt를 Model에 전달하고 LLM이 응답을 생성한다.

---

## 5-3. Output Parser

Model이 생성한 결과를 애플리케이션에서 사용하기 좋은 형태로 변환한다.

오늘 사용한:

```text
StrOutputParser
```

는 Model의 결과에서 최종적으로 사용할 **문자열 형태의 출력**을 얻기 위해 사용한다.

---

## 5-4. 전체 Chain

```python
chain = prompt_template | model | parser
```

이 한 줄은 개념적으로:

```text
입력
 ↓
Prompt 생성
 ↓
LLM 호출
 ↓
결과 Parsing
 ↓
최종 Output
```

이라는 하나의 Pipeline을 구성한다.

즉, 각각을 따로 실행하는 대신 LangChain을 통해 **하나의 연결된 데이터 처리 흐름**으로 표현할 수 있다.

> **Chain = 여러 처리 단계를 순서대로 연결하여 앞 단계의 결과를 다음 단계로 전달하는 구조**

---

## 🔗 오늘의 흐름

```text
LLM Application
       │
       ▼
   LangChain
       │
       ├──────────────┐
       ▼              ▼
 Abstraction     Prompt Template
                      │
                      ▼
                 Variable 치환
                      │
                      ▼
                    Model
                      │
                      ▼
                    Parser
                      │
                      ▼
                   Output

             이 흐름을 연결
                      ↓
                    LCEL
                      ↓
prompt_template | model | parser
```

### 오늘의 핵심

> **LangChain은 LLM 애플리케이션의 여러 구성 요소를 공통적인 방식으로 다룰 수 있도록 추상화하고, Prompt Template으로 입력을 구성한 뒤 Model과 Parser를 LCEL로 연결하여 하나의 Chain으로 만들 수 있게 해준다.**

### 한 줄로 기억하기

```text
Template에 입력을 넣고
→ Model이 답을 만들고
→ Parser가 결과를 정리하며
→ LCEL이 이 과정을 하나의 Chain으로 연결한다.
```

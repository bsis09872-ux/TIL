# LLM Prompt Engineering - Runnable Interface

> 📅 DATE: 2026-09-21 월요일

## 😊 SUMMARY

LangChain에서는 Prompt → Model → Parser처럼 여러 단계를 **Chain으로 연결**하고, 이를 동일한 `Runnable` 인터페이스로 실행할 수 있다.  
`invoke`, `stream`, `batch`를 이용해 **단건·스트리밍·일괄 처리** 방식을 상황에 맞게 선택할 수 있고, 비동기 방식도 동일한 구조로 제공된다.  
덕분에 각 단계의 실행 방식을 통일하고 조합하기 편하지만, 단순한 작업에서는 Runnable 구조가 오히려 코드의 추상화와 복잡도를 높일 수 있다.

**Keywords:** `LCEL`, `Chain`, `Runnable`, `invoke`, `stream`, `batch`, `async`, `RunnableLambda`, `@chain`

---

# 📚 LECTURE NOTE

## 1. Chain과 Runnable

기존에 학습한 LCEL에서는 `|`를 이용해 여러 단계를 하나의 Chain으로 연결한다.

```python
chain = prompt | model | parser
```

각 단계가 `Runnable` 인터페이스를 구현하면 **같은 실행 방식으로 Chain을 다룰 수 있다.**

```text
Prompt → Model → Parser
         ↓
     Runnable
```

> **Runnable** → LangChain에서 여러 구성 요소를 **실행하고 연결할 수 있도록 공통된 실행 방법을 제공하는 인터페이스**

---

## 2. 동기식 실행

### `invoke(...)`

입력 하나를 전달하고 **최종 결과 하나를 한 번에 반환**한다.

```python
result = chain.invoke({"topic": "AI"})
```

### `stream(...)`

결과가 만들어지는 대로 **여러 Chunk로 나누어 순차적으로 반환**한다.

```python
for chunk in chain.stream({"topic": "AI"}):
    print(chunk, end="")
```

> 모델과 Chain 구성에 따라 Chunk의 단위가 달라질 수 있으므로, 항상 정확히 **토큰 하나씩** 반환된다고 보는 것은 아니다.

### `batch(...)`

여러 입력을 **한 번에 처리**할 때 사용한다.

```python
results = chain.batch([
    {"topic": "AI"},
    {"topic": "Python"}
])
```

### 한눈에 보기

| Method | 용도 |
|---|---|
| `invoke()` | 입력 1개 → 결과 1개 |
| `stream()` | 결과를 Chunk 단위로 순차 출력 |
| `batch()` | 여러 입력을 일괄 처리 |

---

## 3. 비동기식 실행

비동기 환경에서는 앞에 `a`가 붙은 메서드를 사용한다.

- `ainvoke(...)` → 비동기 `invoke`
- `astream(...)` → 비동기 `stream`
- `abatch(...)` → 비동기 `batch`

```python
async def main():
    result = await chain.ainvoke({"topic": "AI"})
    return result
```

> 비동기 코드는 **Coroutine 환경**에서 실행하며, 실행 흐름을 관리하기 쉽도록 `async def` 함수 안에서 사용하는 방식을 주로 활용한다.

### 동기 ↔ 비동기

| 동기 | 비동기 |
|---|---|
| `invoke()` | `ainvoke()` |
| `stream()` | `astream()` |
| `batch()` | `abatch()` |

---

## 4. `RunnableLambda`

일반 Python 함수를 **Runnable 객체로 매핑**할 때 사용할 수 있다.

```python
from langchain_core.runnables import RunnableLambda

def add_one(x):
    return x + 1

runnable = RunnableLambda(add_one)
```

이제 일반 함수도 Runnable처럼 실행할 수 있다.

```python
runnable.invoke(10)
```

→ `11`

### LCEL에서 일반 함수 사용

앞선 Chain이 Runnable인 경우, `|` 뒤에 연결한 일반 함수는 LCEL에서 **RunnableLambda로 자동 변환하여 연결**할 수 있다.

```python
chain = prompt | model | my_function
```

> **`RunnableLambda` = 일반 Python 함수를 Runnable로 감싸 Chain에 연결할 수 있도록 해주는 객체**

---

## 5. `@chain`

`@chain` 데코레이터를 이용하면 함수를 **Runnable 객체로 변환**할 수 있다.

```python
from langchain_core.runnables import chain

@chain
def my_chain(input):
    return input.upper()
```

따라서 해당 함수도 Runnable의 실행 방식을 사용할 수 있다.

```python
my_chain.invoke("hello")
```

### `RunnableLambda` vs `@chain`

| 방식 | 핵심 |
|---|---|
| `RunnableLambda(function)` | 일반 함수를 Runnable로 감싸기 |
| `@chain` | 데코레이터를 이용해 함수를 Runnable로 만들기 |

---

## 🔗 오늘의 흐름

```text
prompt | model | parser
        ↓
      Chain
        ↓
Runnable 공통 인터페이스
        ↓
동기: invoke / stream / batch
비동기: ainvoke / astream / abatch
        ↓
일반 Python 함수도 연결
        ↓
RunnableLambda / @chain
```

> ⭐ **핵심:** LangChain의 `Runnable`은 Prompt, Model, Parser, 일반 함수 등을 **같은 실행 방식으로 연결하고 실행하기 위한 공통 인터페이스**이다.

## 📝 Learning Method

- 배운 내용을 **내가 이해한 언어로 다시 정리**
- 코드뿐 아니라 **문제 → 원인 → 시도 → 해결 과정**을 기록
- 새롭게 만난 개발 개념은 **DEV Concepts in 5 Lines**로 짧게 정리
- 직접 실습하고 오류를 해결하며 배운 내용을 내 것으로 만들기

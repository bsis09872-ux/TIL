## 기록 방식

- **내 이해 순서대로:** 설명·질문·코드·결과를 관련 내용 가까이에 둡니다.
- **내용을 보존하고 표현은 간결하게:** 이유, 주의점, 시행착오는 생략하지 않습니다.
- **실행 여부를 명확하게:** 강의 예시, 직접 실습, 미확인 결과를 구분합니다.
- **달라진 이해를 기록하기:** 오류나 오래된 설명을 수정하면 이유도 남깁니다.
- **중복보다 연결:** 날짜별 기록은 학습의 맥락을, 개념 노트는 재사용할 설명을 담습니다.

새 TIL을 작성하면 관련 색인을 갱신합니다. 메인 README는 분야나 탐색 구조가 바뀔 때 수정합니다.

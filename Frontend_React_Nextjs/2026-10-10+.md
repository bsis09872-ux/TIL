### B. JavaScript / TypeScript — 변수 선언과 스코프 ⭐

JavaScript와 TypeScript는 `const`, `let`, `var`의 변수 선언 및 Scope 규칙을 공유한다.

#### 1. 선언 · 할당 · 재할당 · 재선언

| 개념          | 설명                                          |
| ------------- | --------------------------------------------- |
| Declaration   | 변수를 선언하는 것                            |
| Assignment    | 변수에 값을 할당하는 것                       |
| Reassignment  | 기존 변수에 값을 다시 할당하는 것             |
| Redeclaration | 동일 Scope에서 같은 이름으로 다시 선언하는 것 |

```javascript
const apiEndpoint = "https://server.com/v1";

// 재할당 불가
apiEndpoint = "https://server.com/v2"; // ❌

let endpoint = apiEndpoint;

// 재할당 가능
endpoint = "https://server.com/v2"; // ✅
```

`const`는 동일한 값을 다시 할당하더라도 오류가 발생한다.

#### 2. `const` · `let` · `var` 비교

| 구분              | `const` | `let` | `var`    |
| ----------------- | ------- | ----- | -------- |
| 재할당            | ❌      | ✅    | ✅       |
| 동일 Scope 재선언 | ❌      | ❌    | ✅       |
| Scope             | Block   | Block | Function |
| 선언 시 초기값    | 필수    | 선택  | 선택     |

```javascript
let count = 1;

count = 2; // ✅ 재할당
let count = 3; // ❌ 재선언

var number = 1;
var number = 2; // ✅ 재선언
```

> ⭐ `let`은 **재할당은 가능하지만 동일 Scope에서 재선언은 불가능**하다.

---

### C. Scope (스코프)

Scope는 **변수에 접근할 수 있는 유효 범위**이다.

#### 1. Block Scope — `const`, `let`

```javascript
let score = 10;

{
  let score = 20;
  console.log(score); // 20
}

console.log(score); // 10
```

- `{}`로 구분되는 블록마다 별도의 Scope를 가진다.
- `if`, `for`, 함수 내부 등에서도 적용된다.
- 서로 다른 Scope에서는 같은 변수명을 사용할 수 있다.

**Variable Shadowing:** 안쪽 Scope에서 바깥 Scope와 동일한 이름의 변수를 선언하여 바깥 변수가 가려지는 현상.

#### 2. Function Scope — `var`

```javascript
function example() {
  if (true) {
    var message = "Hello";
  }

  console.log(message); // Hello
}
```

- `var`는 일반적인 `{}` 블록을 별도의 Scope로 취급하지 않는다.
- 함수 내부에서 선언하면 해당 함수 Scope에서 유효하다.
- 함수 밖에서 선언하면 일반적으로 전역 Scope에 속한다.

```text
const / let
→ Block Scope

var
→ Function Scope
```

---

### D. `const` 객체의 Property 변경

`const`는 **변수 자체의 재할당**을 금지한다. 객체 내부 Property 변경까지 금지하는 것은 아니다.

```javascript
const config = {
  version: 1,
};

config.version = 2; // ✅
config = { version: 3 }; // ❌
```

```text
const config
    ↓
객체 참조 재할당 ❌
    ↓
객체 내부 Property 변경은 가능 ✅
```

단, `Object.freeze()` 또는 TypeScript의 `readonly` 같은 추가 제약이 있다면 변경이 제한될 수 있다.

### E. JavaScript와 TypeScript의 차이

변수 선언 규칙은 같지만, TypeScript는 **Static Type Checking(정적 타입 검사)**을 추가한다.

```typescript
let count = 10;
count = "Hello";
```

| 구분       | 결과             |
| ---------- | ---------------- |
| JavaScript | 정상 실행        |
| TypeScript | 타입 불일치 오류 |

TypeScript에서는 초기값 `10`을 통해 `count`의 타입을 `number`로 추론한다.

```text
JavaScript
→ 실행 중 값의 타입이 바뀔 수 있음

TypeScript
→ 실행 전 타입 검사
→ 타입 불일치를 미리 발견
```

#### 대표 오류

| 상황                           | 오류          |
| ------------------------------ | ------------- |
| `const` 재할당 (TS)            | `TS2588`      |
| `let` / `const` 재선언 (TS)    | `TS2451`      |
| `let` / `const` 중복 선언 (JS) | `SyntaxError` |
| `const` 재할당 (JS)            | `TypeError`   |
| TypeScript 타입 불일치         | `TS2322`      |

## 3. 핵심 정리

1. `const`: 재선언 ❌ / 재할당 ❌
2. `let`: 재선언 ❌ / 재할당 ✅
3. `var`: 재선언 ✅ / 재할당 ✅
4. `const`, `let` → Block Scope
5. `var` → Function Scope
6. `const` 객체는 재할당할 수 없지만 내부 Property는 일반적으로 수정할 수 있다.
7. TypeScript는 JavaScript의 변수 규칙에 정적 타입 검사를 추가한다.

**실무 원칙:** 기본적으로 `const`를 사용하고, 재할당이 필요한 경우에만 `let`을 사용한다. `var`는 가급적 사용하지 않는다.

## 4. 오늘의 학습 연결

```text
변수 선언
const / let / var
      ↓
재선언과 재할당 구분
      ↓
Scope 이해
Block / Function
      ↓
객체와 참조 이해
const Object
      ↓
TypeScript
Type Inference
      ↓
컴파일 단계에서 타입 오류 검사
```

**오늘의 핵심:** 변수 선언 키워드의 차이는 단순히 값을 변경할 수 있는지의 문제가 아니라, **변수가 어느 범위에서 유효한지와 코드를 얼마나 안전하게 관리할 수 있는지**에 연결된다.

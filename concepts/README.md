## 운영 방식

날짜별 TIL은 학습의 흐름을 보존합니다. 개념 노트는 반복해서 찾을 설명만 정리하고 관련 TIL로 연결합니다. 같은 내용을 매번 복사하지 않습니다.

기존 DEV_CONCEPTS_IN_5_LINES의 기록은 내용과 날짜를 보존해 이곳으로 옮겼습니다. 기존 경로를 저장해 두었다면 새 경로로 갱신해 주세요.

독립 실험은 질문·환경·바꾼 조건·시도·관찰 결과·한계를 기록할 때 labs로 분리합니다. 일반적인 강의 실습은 원래 TIL에 둡니다. 현재는 별도 labs 폴더를 만들지 않습니다.
